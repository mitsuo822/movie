# フォントのライセンス（テロップ・サムネイル・図解・Remotion）

> 対象: テロップ・字幕・サムネイル・図解に使うフォントの利用条件。SIL Open Font License（OFL）の条文と公式FAQ、Google Fonts に入っている日本語フォントのライセンス表示、Remotion でフォントを読み込む方法とライセンスの関係、日本の判例での書体の扱い、商用フォント・フリーフォントで確認すべきこと。Minecraft 風のフォント・ロゴの扱いは mcp 側の [Mojang利用ガイドライン.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/rights/Mojang利用ガイドライン.md) で扱う。
> 使う場面: 編集テンプレート（Remotion）に入れるフォントを決めるとき、サムネイルの書式を決めるとき、フォントファイルをリポジトリに置くか決めるとき、新しいフォントを足すとき。
> 調査日: 2026-11-20 ／ mc_version: 該当なし（Minecraft 風フォントは mcp 側のファイル）
> 関連: [Remotion.md](../editing/Remotion.md), [テロップ・字幕.md](../editing/テロップ・字幕.md), [サムネイル.md](../planning/サムネイル.md), [図解・グラフの見せ方.md](../editing/図解・グラフの見せ方.md), [引用と著作権.md](引用と著作権.md), [Mojang利用ガイドライン.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/rights/Mojang利用ガイドライン.md)

## 要点
- OFL 1.1 は、フォントの使用・改変・再配布を無償で認め、フォント単体での販売を禁じる（配布・改変には別に条件がある）。フォントで作った文書には、OFL のままでいる要件が及ばない。【一次】[S1]
- OFL の公式FAQ（1.1-update7、2023年11月）は、動画のタイトル（video titling）を含むデザイン作業に追加の許諾なしで使えるとし、作ったグラフィックは OFL の対象にならず、クレジット表記も必須でないとする。【一次】[S2]
- 条件が付くのはフォントファイル自体を配る・束ねる・改変するとき。配るなら著作権表示とライセンス文を付け、改変版には予約フォント名（RFN）を使えない。形式の変換・サブセット化も原則として改変に当たる。【一次】[S1][S2]
- Google Fonts のファイルのリポジトリでは、最上位のディレクトリ名がライセンスを表す（大半が OFL 1.1、一部 Apache 2、Ubuntu Font License）。【一次】[S3]
- Noto Sans JP・M PLUS Rounded 1c・Zen Maru Gothic・Dela Gothic One・BIZ UDPGothic はメタデータで OFL。Noto Sans JP には Adobe の RFN『Source』が付いている。【一次】[S4][S5][S6][S7][S8]
- Remotion の資料は、フォントの読み込み方として `@remotion/google-fonts`（v3.2.40〜）、`public/` のファイルを読む `@remotion/fonts`（v4.0.164〜）、CSS の import、FontFace API を挙げる。`@remotion/google-fonts` の資料の License 欄は MIT で、読み込む各フォントのライセンスには触れていない。【一次】[S9][S10]
- 最高裁（ゴナU事件、平成12年9月7日）は、印刷用書体が著作物になるには顕著な特徴を持つ独創性と美術鑑賞の対象となる美的特性の両方が要る、とした。【二次】[S11]
- テレビ番組のテロップ・DVDでのフォント使用に追加許諾料などを求めた訴訟（テレビ朝日・IMAGICA事件）は、一審・控訴審とも請求が退けられた。【二次】[S11]
- フォント制作者の記事は、収益化した YouTube のサムネイルを商用利用の例に挙げ、商用可のフォントでもファイルを人に渡す・販売するのは不可、ロゴの商標登録はほぼすべてのフォントで禁止、とする（筆者の認識）。【二次】[S12]
- Minecraft の利用ガイドラインはブランドの定義にフォントを含める。Minecraft 風フォントは mcp 側のファイルで確認する。【一次】[S13]
- 商用フォント（Adobe Fonts・モリサワなど）と Windows 付属フォントの動画・サムネイルでの条件は、公式ページを読めていない。【未確認】[S14]

## 詳細

### OFL 1.1 の条文（ライセンス本体）
OFL 1.1 の版の日付は 2007年2月26日。Google Fonts の Noto Sans JP のディレクトリにある OFL.txt で読んだ。【一次】[S1]
> 「SIL OPEN FONT LICENSE Version 1.1 - 26 February 2007」[S1]

前文は、OFL のフォントは単体で売らない限り自由に使い・調べ・改変し・再配布できる、と書く。【一次】[S1]
> 「（訳）OFL は、ライセンスされたフォントを、それ単体で販売しない限り、自由に使用、研究、改変、再配布することを認める。」[S1]
> 「The OFL allows the licensed fonts to be used, studied, modified and redistributed freely as long as they are not sold by themselves.」[S1]

フォントを使って作った文書には、OFL のままでいる義務が及ばない。【一次】[S1]
> 「The requirement for fonts to remain under this license does not apply to any document created using the fonts or their derivatives.」[S1]

許諾の範囲は、使用・研究・複製・結合・埋め込み・改変・再配布、改変版と原版の販売（条件付き）。【一次】[S1]
> 「to use, study, copy, merge, embed, modify, redistribute, and sell modified and unmodified copies of the Font Software」[S1]

条件は5つ。【一次】[S1]

| 番号 | 条件の内容（要約） | 確度 | 出典 |
|---|---|---|---|
| 1 | フォントソフトウェアもその部品も、原版・改変版とも、単体で販売してはならない | 【一次】 | [S1] |
| 2 | ソフトウェアに同梱・再配布・販売するときは、各コピーに著作権表示とこのライセンスを含める（別ファイル、読める形のヘッダ、利用者が見られるメタデータのどれでもよい） | 【一次】 | [S1] |
| 3 | 改変版は、著作権者の書面の許可がない限り予約フォント名（RFN）を使えない。この制限は利用者に示される主たるフォント名だけに適用される | 【一次】 | [S1] |
| 4 | 著作権者・作者の名前を、改変版の宣伝・推奨に使ってはならない（貢献の表示や許可がある場合を除く） | 【一次】 | [S1] |
| 5 | フォントソフトウェアは全体でも一部でも OFL だけで配布する。フォントで作った文書にはこの要件は及ばない | 【一次】 | [S1] |

条件を1つでも満たさないとライセンスは無効になる。【一次】[S1]
> 「This license becomes null and void if any of the above conditions are not met.」[S1]

改変版（Modified Version）の定義には、形式の変更と、新しい環境への移植が入っている。【一次】[S1]
> 「by changing formats or by porting the Font Software to a new environment」[S1]

### OFL の公式FAQ（版: 1.1-update7、2023年11月）
FAQ の版と日付は 1.1-update7、2023年11月。SIL のフォントのリポジトリに同梱された OFL-FAQ.txt で読んだ。【一次】[S2]
> 「Version 1.1-update7 - November 2023」[S2]

**デザインへの使用（1.1）**: 印刷物、ロゴやその他のグラフィックに使える。例の中に動画のタイトルが入っている。追加の許諾は要らない。【一次】[S2]
> 「（訳）OFL でフォントを公開した作者は、そのフォントソフトウェアをあらゆる種類のデザイン作業に使うことを認めている。」[S2]
> 「Authors of fonts released under the OFL allow you to use their font software as such for any kind of design work.」[S2]
> 「Some examples of these uses are: logos, posters, business cards, stationery, video titling, signage」[S2]

**作品の権利（1.1.1）**: 作ったグラフィックや物の著作者・著作権者は作った人のまま。ライセンスの条件が問題になるのは、フォント自体を再配布・同梱・改変するときだけ。【一次】[S2]

**クレジット表記（1.1.2）**: 必須ではない。作者は、フォント名とサイトへのリンク付きで謝辞に載ると喜ぶかもしれない、とFAQは書く。【一次】[S2]
> 「Font authors may appreciate being mentioned in your artwork's acknowledgements alongside the name of the font, possibly with a link to their website, but that is not required.」[S2]

**グラフィックはOFLの対象外（1.13）**: 文書でOFLフォントを参照・埋め込みしても文書のライセンスは変わらない。OFLフォントで作ったグラフィックも OFL の対象にならない。【一次】[S2]
> 「Similarly, creating any kind of graphic using a font under the OFL does not make the resulting artwork subject to the OFL.」[S2]

**埋め込み（1.11・1.12）**: 埋め込みは、抽出・再配布が難しい（またははっきり抑止される）形で文書やファイルに入れること。それ以外の手段でフォントを人に渡すのは配布で、OFL.txt の著作権表示とライセンス情報を付ける。文書への埋め込みは全体でもサブセットでもよい。【一次】[S2]

**ライセンス文を付けなくてよい場合（1.10）**: 文書に埋め込むか、プログラムの中に束ねる場合だけ。【一次】[S2]
> 「The only situation in which an OFL font can be distributed without the text of the OFL (either in a separate file or in font metadata), is when a font is embedded in a document or bundled within a program.」[S2]

**Webサイトで配る（1.8）**: フォントの全パッケージを提供すれば可。原版の配布元に誘導するのがよい場合が多い、とする。【一次】[S2]

**Webページでの使用（2.1）**: CSS の `@font-face` で読み込む方法を勧めていて、ライセンス上は配布として明示的に認められている。【一次】[S2]
> 「This is recommended and explicitly allowed by the licensing model because it is distribution.」[S2]

**WOFF/WOFF2 への変換（2.2・2.2.1・2.2.2）**: 形式の変更は通常は改変で、RFN を使えない。ただし、元のフォントデータを WOFF の圧縮以外で変えず、WOFF 固有のメタデータを省くか、入れるなら元のフォントの同等のメタデータをすべて変えずに含めるなら、名前を変えずに作成・使用・配布できる（2.2.1）。変換ツールやサービスがこの条件を自動で満たすとは限らない（2.2.2）。【一次】[S2]
> 「A change in font format normally is considered modification, and Reserved Font Names (RFNs) cannot be used.」[S2]
> 「Some WOFF conversion tools and online services do not meet the two requirements listed above, and so their output must be considered a Modified Version.」[S2]

**サブセット化（2.6）**: Webフォントを渡すときに使わないグリフなどを除くのは改変。OFL は許しているが、通常は RFN を使えなくなる。【一次】[S2]
> 「Removing any parts of the font when delivering a webfont to a browser, including unused glyphs and smart font code, is considered modification.」[S2]

**RFN の範囲（5.3・5.4・5.7）**: RFN はフォントメニュー名など、文書の中でフォントを指定する仕組みに及ぶ。RFN の単語をそのまま使うことはできないが、単語の一部なら使える（勧めはしない）。v1.1 からは、著作権表示の後に指定した名前だけが RFN になる（既定で予約される名前はない）。【一次】[S2]
> 「If you want any names to be Reserved Font Names, they must be specified after the copyright statement(s).」[S2]

**AI との関係（1.25・1.26）**: OFL フォントを入力や学習データに含む AI で作ったフォントは派生物とみなされ、OFL のままでなければならない。フォントでないグラフィックを AI ベースのデザインツールで作るのは通常の使用と同じ扱い。【一次】[S2]
> 「Yes, as long as the resulting work is not intended to be a font.」[S2]

**契約かライセンスか（8.3）**: OFL は国際的な著作権の取り決めに基づくライセンスで、契約ではない。署名は要らず、使用・改変・再配布することでライセンスを受け入れたことになる。【一次】[S2]

### Google Fonts のフォントのライセンス
Google Fonts が配信するフォントファイルを集めたリポジトリ（google/fonts）の README は、最上位のディレクトリがその中の全ファイルのライセンスを表す、と書く。各ファミリーのディレクトリには `METADATA.pb` があり、ライセンスの情報が入っている。【一次】[S3]

ライセンスの内訳: 大半は OFL 1.1、一部は Apache 2、Ubuntu のフォントは Ubuntu Font License v1.0。【一次】[S3]

使うフォントごとにライセンスを読むよう求めている。RFN の要件を使っているフォントもあり、改変するときは注意するよう書いている。【一次】[S3]
> 「It is important to always read the license for every font that you use.」[S3]

自前でホストしてよい理由として、ここのフォントはすべて、ライセンスの条件のもとで再配布の許可があることを挙げている。【一次】[S3]
> 「Since all the fonts available here are licensed with permission to redistribute, subject to the license terms, you can self-host using a variety of third-party projects.」[S3]

Google Fonts の公式FAQ は読めていない（下の節『わかっていないこと・要確認』を参照）。

### Remotion でのフォントの読み込み
Remotion の公式資料は、カスタムフォントの読み込み方として、`@remotion/google-fonts`（v3.2.40〜）、Google Fonts の CSS を import する方法、`@remotion/fonts`（v4.0.164〜）で `public/` フォルダのフォントを読む方法、Web 標準の FontFace API を使う方法を挙げている。【一次】[S9]
> 「Put the font into your public/ folder.」[S9]

CSS で読み込む方法について、v2.2 からは Remotion がフォントの読み込みを自動で待つ、と書かれている。【一次】[S9]
> 「From version 2.2 on, Remotion will automatically wait until the fonts are loaded.」[S9]

`@remotion/google-fonts` の資料（2026-11-20 取得時点で v4.0.545 を前提にした記述）では、`loadFont()` に style・weights・subsets を渡して読み込む量を絞るよう勧めている。Remotion 4.0 では引数なしで呼ぶと全スタイル・全ウェイト・全サブセットを読み込み、v5.0 からは weights と subsets が必須になる。【一次】[S10]
> 「In Remotion 4.0, calling it without arguments loads every style, weight and subset, which can cause unnecessary requests.」[S10]

`getInfo()` の値の例では、フォントファイルの URL が fonts.gstatic.com を指している（例は Titan One）。【一次】[S10]

同じ資料の License 欄は MIT。これは `@remotion/google-fonts` パッケージの欄で、読み込む各フォントのライセンスについては書かれていない。【一次】[S10]

日本語フォントを読み込むときのリクエスト数・豆腐（□）の問題は [Remotion.md](../editing/Remotion.md) で扱う。

### 日本の判例での書体の扱い（弁護士の解説記事による）
以下は、弁護士 菅原洸介 氏の note 記事（2026年10月11日）による。判決文そのものは読めていない。【二次】[S11]

ゴナU事件（最判平成12年9月7日民集54巻7号2481頁）は、写研が「ゴナU」「ゴナM」の権利を主張し、被告側の新ゴシック体の書体をめぐって争った事件。大阪地裁・大阪高裁は請求を退け、最高裁は次の基準を示した。【二次】[S11]
> 「印刷用書体がここにいう著作物に該当するというためには，それが従来の印刷用書体に比して顕著な特徴を有するといった独創性を備えることが必要であり，かつ，それ自体が美術鑑賞の対象となり得る美的特性を備えていなければならないと解するのが相当である。」[S11]

判決は理由として、基準を緩めると、その書体を使った小説・論文などの出版に書体の著作者の氏名表示と著作権者の許諾が必要になる、という懸念を挙げている。【二次】[S11]
> 「この印刷用書体を用いた小説，論文等の印刷物を出版するためには印刷用書体の著作者の氏名の表示及び著作権者の許諾が必要となり」[S11]

判決が条件文を使っているので、保護の可能性は形の上では残っている。一方、実際に基準を満たす書体を想定するのは容易でない、とする見解（泉克幸、『著作権判例百選〔第7版〕』2025年）も記事は紹介している。【二次】[S11]

ゴナU判決の枠組みは下級審でも踏襲されている。映画の予告編・ポスター・パンフレットでタイプフェイスの一部が使われた事案（東京地判平成31年2月28日）も、この基準で著作物性を否定した。【二次】[S11]

**テロップでのフォント使用をめぐる訴訟**: テレビ朝日・IMAGICA事件（大阪地判平成25年7月18日・大阪高判平成26年9月26日）では、原告は書体の著作権侵害ではなく、一般不法行為（主位的請求）と不当利得の返還（予備的請求）を主張し、両審とも請求を退けた。【二次】[S11]
> 「テレビ番組のテロップやDVDにおけるフォント使用について、番組ごとの追加許諾料等が主張された。」[S11]

控訴審は、フォントの販売・使用許諾の営業上の利益は保護の対象になりうるとしつつ、原告の営業方針が商慣習になっているとは認めず、自由競争の範囲を逸脱する特段の事情がある場合に限って不法行為になる、とした。【二次】[S11]
> 「フォントの商用使用に個別の許諾料を要するという原告の営業方針が商慣習又は社会的規範となっているとは認めず」[S11]

この事件では、テレビ朝日はテロップの制作を外注して納品を受けていて、正式な指摘の後は使用を避けていた。IMAGICA も納品済みのテロップ画像を映像に入れる編集をしただけで、無許諾使用を疑うべき事情は認められなかった。【二次】[S11]

同じ記事は、著作権が成立しないことから模倣を含む競業行為が常に適法、という結論にはならない、として一般不法行為の検討を続けている。【二次】[S11]
> 「著作権が成立しないことから、模倣を含む競業行為が常に適法であるという結論まで直ちに導かれるわけでもない。」[S11]

この記事は書体（字形のデザイン）の著作物性と不法行為を扱っていて、フォントのデータ（ソフトウェア）の扱いや、購入時の使用許諾の条件の効力については書いていない。【二次】[S11]

### フォントの制作者が書く商用利用の注意点
フォントを作って販売している『バニラビーンズ』の note 記事（2026年5月14日）による。筆者はフォントの作り手の立場で書いていて（本文の自己紹介）、自作フォント（Booth で販売）の宣伝を含む。法令や判例は引いていない。【二次】[S12]

商用利用には、直接お金をもらう場面だけでなく、間接的に収益につながる使い方も含まれる、とし、例に収益化している YouTube のサムネイルを挙げる。【二次】[S12]
> 「収益化しているYouTubeのサムネイルに使う」[S12]

Google Fonts のフォントは基本的に商用利用できるが、フォントによって OFL や Apache 2.0 などライセンスが違う、と注意している。【二次】[S12]

商用可のフォントでも、フォントファイルを他人に渡す・販売するのは禁止、と書く。【二次】[S12]
> 「商用可フォントであっても、フォントファイル自体を他の人に渡したり、販売したりするのはアウトです。」[S12]

ロゴへの使用は問題ないことが多いが、そのロゴの商標登録はほぼすべてのフォントで禁止されている、と書く（記事の筆者の認識で、調査の範囲は示されていない）。【二次】[S12]
> 「そのロゴを商標登録するのはほぼすべてのフォントで禁止されています。」[S12]

同じ作者のフォントでも、一部（『カフェもじ』『Chig-hug』の無料お試し版）は個人利用のみで、それ以外は無料お試し版・製品版とも商用利用可、と書いている。同じ作者のフォントでも版によって条件が違う例。【二次】[S12]

記事のまとめは、フォントにも著作権がある、と書く（どの権利を指すかの説明はない。下の節『わかっていないこと・要確認』を参照）。【二次】[S12]
> 「フォントにも著作権がある」[S12]

### Minecraft 風のフォント
Minecraft の利用ガイドライン（ゲームのバージョンによらない文書。2026-11-20 取得時点の文面）は、ブランド（brand）の定義に、名前・ロゴとともにフォントとテクスチャを含めている。ゲーム内の文字に似せたフォントやロゴ風の文字をタイトル・サムネイル・チャンネルロゴに使う場合の扱いは、mcp 側の [Mojang利用ガイドライン.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/rights/Mojang利用ガイドライン.md) を読む。【一次】[S13]
> 「related logos, fonts, textures」[S13]

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。

- テロップ・サムネイル・図解の標準フォントは、Google Fonts の OFL のフォント（例: Noto Sans JP、M PLUS Rounded 1c、Zen Maru Gothic、Dela Gothic One、BIZ UDPGothic）から選ぶ。OFL は動画のタイトルを含むデザイン用途を追加の許諾なしで認め、出来上がった動画・画像に条件が及ばない。（根拠: [S1][S2][S4][S5][S6][S7][S8]）
- 新しいフォントを足すたびに、フォント名・入手元のURL・ライセンス（METADATA の license とライセンス文）・取得日を一覧に記録する。Google Fonts でもフォントごとにライセンスが違いうる。（根拠: [S3][S12]）
- フォントファイルを Git リポジトリ（Remotion の `public/`）に置く場合、リポジトリを公開するなら配布に当たる前提で扱い、OFL.txt を同じ場所に置く。商用フォントやライセンスを読んでいないフォントのファイルは、リポジトリに入れない。（根拠: [S1][S2][S9][S12]）
- フォントは入手したファイルをそのまま使い、自分で WOFF2 への変換やサブセット化をしない。変換・サブセット化は改変に当たりうるため、RFN 付きのフォント（Noto Sans JP など）で名前の扱いの判断が要る。Google Fonts のファイルを使うなら `@remotion/google-fonts` で weights と subsets を指定して読み込むのが手間が少ない。（根拠: [S1][S2][S4][S9][S10]）
- クレジットは OFL では必須でないが、説明欄の定型文に使用フォント名を書いておく。（根拠: [S2]）
- チャンネルロゴにフォントの文字を使う場合、商標登録はしない前提にする。登録を考えるならフォントの規約を先に読む。（根拠: [S12]）
- 書体の著作物性は日本では狭く認められているが、それを理由に規約を読まずに商用フォントを使うことはしない。テロップでのフォント使用が訴訟になった例があり、規約・使用許諾の条件は別に効く可能性がある。（根拠: [S11]）
- Minecraft 風のフォントやロゴ風の文字は、チャンネル名・ロゴ・サムネイルに使う前に mcp 側の利用ガイドラインのファイルで確認する。（根拠: [S13]）
- 商用フォント（Adobe Fonts・モリサワなど）を使いたくなったら、その時点で公式の使用許諾を自分で読み、このファイルに原文つきで追記してから使う。（根拠: [S14]）

## わかっていないこと・要確認
- Google Fonts の公式FAQ（https://developers.google.com/fonts/faq → https://fonts.google.com/faq に転送）は、プロキシで拒否され読めなかった（2026-11-20 の照合で再度試しても同じ）。Google Fonts として動画・画像での使用をどう説明しているかは未確認。
- バニラビーンズの記事（[S12]）がまとめで書く「フォントにも著作権がある」が、フォントのデータ（ソフトウェア）の権利と字形（書体のデザイン）の権利のどちらを指すか。記事には説明がない。字形については、日本の判例は著作物性の要件を厳しくしている（[S11]）。
- Noto Sans JP（RFN『Source』）を WOFF2 に変換したり、サブセット化したりしたファイルを『Noto Sans JP』の名前のまま使ってよいか。FAQ 5.4 の当てはめでは問題ないように読めるが、Adobe や Google の説明は読めていない。
- `@remotion/google-fonts` がレンダリングのたびに fonts.gstatic.com から取得するのか、オフラインで動くのか（資料からは URL の向き先しかわからない）。
- Remotion Lambda などクラウドでレンダリングする場合、`public/` のフォントファイルをクラウドに上げることが、商用フォントの規約上の再配布やサーバーへのインストールに当たるか。
- Adobe Fonts の動画・YouTube での使用条件（検索要約のみ）、モリサワ（MORISAWA PASSPORT）・フォントワークス（LETS）の動画配信・サムネイル・プログラム（Remotion）でのレンダリングの扱い。公式ページはこのセッションでは読めないホスト。
- Windows 付属フォント（游ゴシック・メイリオ等）を動画・サムネイルに使う条件（Microsoft の一次資料は読めないホスト）。
- 個人が配布するフリーフォント（例: けいふぉんと）の個別の規約は読んでいない。条件が作者ごとに違うという一般論（[S12]）しか確認できていない。
- フォントのデータ（ソフトウェア）がプログラムの著作物として保護されるか、購入時の使用許諾が日本法でどこまで効くか。読んだ弁護士の記事（[S11]）はこの点を扱っていない。
- Apache License 2.0 と Ubuntu Font License のフォントの条件（今回は条文を読んでいない）。IPAフォント（IPAフォントライセンス）の条件も未読。
- ファンが作った Minecraft 風フォントの個別のライセンスと、利用ガイドラインのブランドの定義（fonts）との関係（mcp 側の未解決の問いと同じ）。
