# 著作権とContent ID

> 対象: YouTube の Content ID による著作権の申し立て（claim）と、著作権侵害の警告（strike）の違い、異議申し立て・再審査請求の流れ、収益への影響、3回でチャンネル停止になるルール、フリーBGMなどへの誤った申し立ての扱い。
> 使う場面: BGM・効果音・素材を選ぶとき、非公開アップロード後に申し立てを確認するとき、申し立てや警告を受けたとき。
> 調査日: 2026-11-19 ／ mc_version: 該当なし（Minecraft の映像・音楽の権利は [Mojang利用ガイドライン.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/rights/Mojang利用ガイドライン.md) と [マイクラ音楽の使用.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/rights/マイクラ音楽の使用.md) を参照）
> 関連: [ショートの仕様.md](ショートの仕様.md), [収益化の条件.md](収益化の条件.md), [../audio/BGMと効果音.md](../audio/BGMと効果音.md), [../legal/引用と著作権.md](../legal/引用と著作権.md), [チャプター・カード・終了画面.md](チャプター・カード・終了画面.md)

## 要点
- Content ID は著作権者が送ったファイルのデータベースと照合する自動識別システムで、アップロードされた動画は自動的にスキャンされる。 【一次】[S1]
- 一致すると Content ID の申し立て（claim）が付き、著作権者の設定に応じてブロック・収益化・トラッキングのいずれかになる。国や地域ごとに違う設定もできる。 【一次】[S1][S2]
- 申し立て（claim）と著作権侵害の警告（strike）は別物。申し立ては動画に影響するが、通常はチャンネルやアカウントには影響せず、警告も出ない。 【一次】[S2][S3]
- 警告は、法的な削除通知でコンテンツが削除されたことを意味する。3回目の警告でアカウントに関連付けられたチャンネルがすべて停止され、新しいチャンネルも作れない。 【一次】[S3]
- 2026-11-19 時点の日本語ヘルプでは、警告が90日で期限切れになる条件に「コピーライト スクールを修了」していることが含まれている。修了しないと警告は残る。 【一次】[S3]
- 申し立てへの異議申し立てに正当な理由なく反論すると、著作権者が削除通知を出し、警告につながることがある。 【一次】[S2][S3][S4]
- 異議申し立てを出すと申立人に30日の対応期限が与えられ、30日以内に対応がなければ申し立ては期限切れで取り下げられる。再審査請求の回答期限は7日。 【一次】[S4]
- 申し立てから5日以内に異議を出すと、申し立て初日にさかのぼって収益が保留され、解決後に適切な当事者に支払われる。何もしないと5日経過後に保留分は申立人に支払われる。 【一次】[S5]
- 1〜3分のショート動画は、有効な申し立てが1つでもあればポリシーに関係なくブロックされる。 【一次】[S2]
- 申し立てを受けた部分は、曲の消去（ミュート）・セグメントのカット・オーディオライブラリの曲への置き換えで外すことができ、正しく行えば申し立ては自動的に削除される。 【一次】[S2]
- 誤った申し立てを繰り返す申立人は、Content ID へのアクセスを無効にされることがある（YouTube 側の運用の説明）。 【一次】[S1]

## 詳細

### Content ID の仕組み
Content ID は YouTube の自動コンテンツ識別システムで、一部の著作権者が自分のコンテンツを識別・管理するために使う。 【一次】[S1]
> 「Content ID は、著作権の所有者から送信された音声ファイルと映像ファイルのデータベースを使用して、著作権で保護されたコンテンツと一致するものを特定します。」[S1]
> 「動画が YouTube にアップロードされると、Content ID によって自動的にスキャンされます。」[S1]

一致したときに著作権者の設定によって行われる対応は次の3つ。 【一次】[S1][S2]

| 対応 | 内容 | 確度・出典 |
|---|---|---|
| ブロック | 動画を視聴できないようにする（全世界、または特定の国・地域のみ） | 【一次】[S1][S2] |
| 収益化 | 動画に広告を掲載して収益化し、場合によってはアップロードしたユーザーと収益を分配する | 【一次】[S1][S2] |
| トラッキング | 視聴に関する統計情報を追跡する | 【一次】[S1][S2] |

- 対応は地域別に設定でき、ある国では収益化、別の国ではブロックといったことができる。 【一次】[S1][S2]
- 著作権者は、コンテンツが表示されるアプリやウェブサイトを制限することもある。この場合でも YouTube での視聴はできる。 【一次】[S2]
- 3分を超える動画で、申し立てのポリシーがトラッキングか収益化なら、申し立てが有効でも視聴できる。音楽の申し立てで最も一般的なポリシーは収益化だと YouTube は説明している。 【一次】[S2]
- 申し立てがあった場合の広告の扱いについて、ヘルプは次のように書いている。 【一次】[S2]
> 「広告は、動画が再生される前に挿入されるか、または動画の長さが 8 分以上の場合は動画の再生中に表示されます。」[S2]

### 誰が Content ID を使えるか
Content ID は一定の基準を満たす著作権者だけが使える。 【一次】[S1]
> 「著作権者が承認を受けるには、YouTube に頻繁にアップロードされる大量コンテンツの独占的権利所有者である必要があります。」[S1]

YouTube は Content ID の使用と異議申し立てを継続的にモニタリングしているとしている。 【一次】[S1]
> 「誤った Content ID の申し立てを繰り返す著作権の申立人に対しては、Content ID へのアクセスを無効にしたり、YouTube とのパートナー関係を解消したりすることがあります。」[S1]

手動申し立て（Content ID で一致が出ない動画に申立人が手で付ける申し立て）は、ツールが必要なことを証明し Content ID の高度な知識を持つ申立人だけが使える。 【一次】[S2]
> 「手動申し立てでは、申し立ての対象となったコンテンツをクリエイターが正確に把握できるよう、正確なタイムスタンプを含める必要があります。」[S2]

不正確なタイムスタンプを繰り返す申立人はツールへのアクセスを取り消されることがあり、タイムスタンプが正確でないと思うクリエイターはクリエイター サポートに問い合わせるよう案内されている。 【一次】[S2]

### 申し立て（claim）と警告（strike）の違い

| 項目 | 著作権の申し立て（Content ID） | 著作権侵害の警告 | 確度・出典 |
|---|---|---|---|
| 発生のしかた | Content ID の一致で自動的に生成（手動申し立てもある） | 法的な著作権侵害による削除通知が審査され、妥当とされたとき | 【一次】[S2][S3] |
| 動画への影響 | ブロック・収益化・トラッキング | 動画が YouTube から削除される | 【一次】[S2][S3] |
| チャンネルへの影響 | 通常はチャンネルやアカウントに影響しない | 3回目でアカウントに関連付けられたチャンネルがすべて停止 | 【一次】[S2][S3] |
| コミュニティガイドライン違反警告との関係 | （S2・S3 に直接の記載なし） | 別物 | 【一次】[S3] |

> 「著作権の申し立ては動画に影響しますが、通常はチャンネルやアカウントには影響しません。」[S2]
> 「動画に対して Content ID の申し立てが行われた場合、通常は著作権侵害の警告は出されません。」[S3]

ただし、正当な理由なく申し立てに異議を出すと、著作権者が削除通知を出すことがあり、それが妥当なら動画は削除され警告が付く。 【一次】[S2][S3]

### 著作権侵害の警告（strike）と3回ルール
- 公式の通知は no-reply@youtube.com からメールで届く。 【一次】[S3]
- 1回目・2回目: コンテンツが削除される。コピーライト スクールを修了すると90日で期限切れになり、修了しないと有効なまま残る。 【一次】[S3]
- 3回目: アカウントに関連付けられたチャンネルがすべて停止され、アップロード済みコンテンツにアクセスできなくなり、新しいチャンネルも作れない。 【一次】[S3]
> 「コピーライト スクールを修了し、チャンネルの著作権侵害の警告が 3 回未満であれば、著作権侵害の警告は 90 日で期限切れになります。」[S3]
> 「90 日以内に著作権侵害の警告を 3 回受けると、チャンネルは停止されます。」[S3]
> 「新しい YouTube チャンネルを作成することはできません。」[S3]
- 1本の動画に付く警告は一度に1回だけ。 【一次】[S3]
> 「動画に対して著作権侵害の警告が発せられるのは、一度に 1 回だけです。」[S3]
- コピーライト スクールは4つの質問からなり、修了が必要なのは1回だけ。修了すると警告は適用日から90日後に解除される。 【一次】[S3]
> 「コピーライト スクールは、YouTube での著作権の仕組みに関する 4 つの質問から構成されています。」[S3]
- 警告を解除する方法は3つ: コピーライト スクールを修了して90日待つ、削除通知を出した人に撤回してもらう、有効な異議申し立て通知を出す。 【一次】[S3]
- 削除通知に期限が設定されている場合は、7日以内にコンテンツを削除すれば警告を回避できる。期限がなければ、動画を消しても警告は解除されない。 【一次】[S3]
> 「期限が設定されていない場合は、動画を削除しても著作権侵害の警告は解除されません。」[S3]
- ライブ配信中のコンテンツが削除されると、ライブ配信へのアクセスが7日間制限され、もう一度警告を受けると制限は14日間になる。 【一次】[S3]
- リンクされているチャンネルが有効な警告を3回受けると、自分のチャンネルも停止される（逆も同じ）。 【一次】[S3]
- 警告の確認は YouTube Studio の [ダッシュボード] の [アクティブな著作権侵害の警告]、または [コンテンツ] の [著作権] フィルタで行う。 【一次】[S3]

### 申し立てを受けたときの選択肢
YouTube Studio の [コンテンツ] で [申し立て] フィルタを使うと、申し立てを受けた動画を探せる。申し立てを受けるとメールも届く。 【一次】[S2]

| 選択肢 | 内容 | 確度・出典 |
|---|---|---|
| 何もしない | 申し立てを残す。後で別の対応もできる | 【一次】[S2] |
| 曲を消去する | 申し立てを受けた音声をミュート。曲だけか、すべての音声かを選べる | 【一次】[S2] |
| セグメントをカットする | 申し立てを受けた区間を削除 | 【一次】[S2] |
| 他の曲に置き換える | 音声トラックを YouTube オーディオ ライブラリの音声に置き換える | 【一次】[S2] |
| 収益を分配する | YouTube パートナー プログラム参加者で、音楽の申し立ての場合に音楽出版社と分配できることがある | 【一次】[S2] |
| 異議申し立て | 申し立てが無効で、必要な権利をすべて持っていると確信できる場合 | 【一次】[S2][S4] |

- 消去・カット・置き換えを正しく行うと、申し立ては自動的に削除される。 【一次】[S2]
- 申立人に見覚えがなくても無効とは限らない。音楽著作権管理団体からの申し立てもある。 【一次】[S2]
> 「著作権者に見覚えがないからといって、申し立てが無効であるとは限りません。」[S2]
- 1本の動画の別々の部分に、別々の申立人から申し立てが付くことがある。国や地域の違う複数の申立人から、同じ部分に複数の申し立てが付くこともある。 【一次】[S2]

### 異議申し立て（dispute）と再審査請求（appeal）
異議申し立ての正当な理由として、YouTube は次の3つを挙げている。 【一次】[S4]
- 動画でコンテンツを使用するために必要な権利をすべて所有している。
- フェアユースなど著作権の例外に該当する方法で使っている。
- 動画が誤認識された、またはエラーが発生したと思われる。

正当な理由に当たらないものとして、著作権者の情報を明示している、動画や曲のコピーを持っている、動画の収益化を無効にしている、の3つが挙げられている。 【一次】[S4]

> 「最終的には、異議申し立ての是非について YouTube は判断できません。」[S4]
> 「YouTube が著作権侵害に関する異議申し立ての仲裁を行うことはありません。」[S2]

YouTube はどのコンテンツに適切なライセンスがあるかを把握しておらず、例外に当たるかも判断できないため、最初の異議申し立ても再審査請求も申立人が審査する、と説明している。 【一次】[S4]

異議申し立て後に申立人が取れる対応: 【一次】[S4]

| 申立人の対応 | 結果 | 確度・出典 |
|---|---|---|
| 申し立てを取りやめる | 収益化していた場合、収益化の設定が自動的に復元される | 【一次】[S4] |
| 申し立てを復活させる | 異議は却下され申し立ては維持。被申立人は再審査請求ができる | 【一次】[S4] |
| 削除通知を送る | 妥当なら動画は削除され、チャンネルは警告を受ける | 【一次】[S4] |
| 30日以内に対応しない | 申し立ては期限切れで取り下げ | 【一次】[S4] |

> 「申立人には 30 日間の対応期限が与えられます。」[S4]
> 「申立人が 30 日以内に対応しないと、動画に対する申し立ては期限切れとなり、取り下げられます。」[S4]

- 再審査請求では申立人の回答期限は7日。 【一次】[S4]
- [再審査請求にエスカレーションする] は動画をブロックする申し立てにだけ使え、30日の最初の手続きを飛ばして7日の再審査請求から始まる。 【一次】[S4]
- 再審査請求の手続きでは申立人が動画を徹底して審査する。その理由として YouTube は、申立人が申し立てを復活させる場合は動画の削除を維持するために削除通知（法的手続き）を出す必要があり、その後に被申立人が異議申し立て通知を出せば、申立人は削除を維持するために訴訟を起こす必要があるため、と説明している。 【一次】[S4]
- 一度出した異議申し立ては取り消せない。 【一次】[S4]
> 「いいえ、一度提出された異議申し立てを取り消すことはできません。」[S4]
- 異議申し立ての乱用にはペナルティがある。 【一次】[S4]
> 「異議申し立てを繰り返し行ったり、不正に行ったりすると、動画やチャンネルに対してペナルティが科される場合があります。」[S4]
- 判断がつかない場合は、異議を出す前に法律の専門家に相談するよう勧めている。 【一次】[S4]

### 異議申し立て中の収益
- 異議申し立て中も、クリエイターと申立人の両方が望めば動画を収益化できる。 【一次】[S5]
> 「著作権の申し立てを受けてから 5 日以内に著作権の申し立てに対して異議申し立てを行うと、著作権の申し立てが行われた初日にさかのぼって動画の収益が保留されます。」[S5]
- 5日を過ぎてから異議を出すと、異議を出した日から収益が保留される。 【一次】[S5]
- 何もしないと、申し立て日から5日経過後に保留されていた収益は申立人に支払われる。 【一次】[S5]
> 「異議申し立ての手続き中は収益が個別に保留され、異議申し立てが解決された後に、適切な当事者に支払われます。」[S5]
- 再審査請求でも同じく5日以内かどうかで保留の起点が変わる。 【一次】[S5]
- 異議申し立て・再審査請求中の動画は、収益データが YouTube アナリティクスに表示されない。解決後に追加され、月の初めに解決すれば翌月の10〜20日、月末に解決すれば2か月目の10〜20日に表示されることがある。 【一次】[S5]
> 「その動画の収益データは YouTube アナリティクスに表示されません。」[S5]
- 例として、7月12日に異議を出して8月6日に有利に解決した場合、その期間の収益データは9月10日〜20日に表示される、と書かれている。 【一次】[S5]
- 異議申し立て中に収益化したくなければ、YouTube Studio の [動画] ページで収益化を無効にできる。 【一次】[S5]

### ショート動画と申し立て
- 2024-10-15 から、長さ1〜3分の新しい縦向き動画はすべてショートに分類される（公式アーティスト チャンネル等は2025-12-08が期限）。 【一次】[S2]
> 「申し立てを受けた動画は、有効な申し立てが 1 つでも適用されていれば、ポリシーに関係なくブロックされます。」[S2]
- 申し立てを受けたコンテンツを削除するか、誤りなら異議申し立てをして、解決すれば視聴できるようになる。 【一次】[S2]
- ショート全般の仕様は [ショートの仕様.md](ショートの仕様.md) を参照。

### フリーBGM・素材への申し立て（誤った申し立てを含む）
YouTube 側の公式説明で、誤った申し立てに関係するのは次の点。
- 異議申し立ての正当な理由の1つが、動画が誤認識された・エラーが発生したと思われる場合。 【一次】[S4]
- 誤った申し立てを繰り返す申立人は Content ID へのアクセスを無効にされることがある。 【一次】[S1]
- 申立人に見覚えがなくても無効とは限らない。 【一次】[S2]

フリーBGMサイト側の規約（DOVA-SYNDROME など）は原文を読めていないため、この節には事実として書かない。検索要約で得た内容は『わかっていないこと・要確認』の節に置く。BGM・効果音の選び方と規約の詳細は [../audio/BGMと効果音.md](../audio/BGMと効果音.md) で扱う。

## このチャンネルでの使い方（提案）

- 非公開でアップロードした段階で、Studio の [申し立て] フィルタで申し立ての有無を確認し、なくなってから公開する。アップロード時に自動スキャンされるため。 （根拠: [S1][S2]）
- BGM・効果音・素材ごとに、配布ページのURL・規約の版・ダウンロード日を記録しておく。異議申し立ての正当な理由は「必要な権利をすべて所有している」ことなので、その根拠をすぐ出せるようにする。 （根拠: [S4]）
- 申し立てが付いたら、まず5日以内に方針を決める。異議を出すなら5日以内に出せば、申し立て初日からの収益が保留される。 （根拠: [S5]）
- 権利を確信できない申し立てには異議を出さず、曲の消去・カット・置き換えで外す。根拠のない異議は削除通知と警告につながりうる。 （根拠: [S2][S3][S4]）
- ショートは申し立てが1つでもあるとブロックされるため、ショートには申し立ての前例がない音源だけを使う。 （根拠: [S2]）
- 警告を受けたら、コピーライト スクールをすぐ修了する。修了しないと警告が残る。 （根拠: [S3]）
- 長尺の BGM で申し立ての出やすいものは、その動画の素材リストに記録して次から使わない。 （根拠: [S1][S2]）
