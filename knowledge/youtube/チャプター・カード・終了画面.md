# チャプター・カード・終了画面

> 対象: 視聴者を動画内・別の動画へ誘導する YouTube の機能。チャプター（手動・自動）、終了画面、情報カード、固定コメント、ショートの関連動画、クリックできるリンクの範囲。
> 使う場面: 編集（Remotion のテンプレートで終了画面の尺を空ける）、説明欄の作成、アップロード後の Studio での設定、ショートから長尺への誘導を決めるとき。
> 調査日: 2026-11-19 ／ mc_version: 該当なし
> 関連: [子ども向け設定.md](子ども向け設定.md), [ショートの仕様.md](ショートの仕様.md), [アナリティクス指標.md](アナリティクス指標.md), [著作権とContent_ID.md](著作権とContent_ID.md), [../channel/新規チャンネルの立ち上げ.md](../channel/新規チャンネルの立ち上げ.md), [../script/維持率を上げる構成.md](../script/維持率を上げる構成.md)

## 要点
- 手動のチャプターは、説明欄にタイムスタンプとタイトルの一覧を書く。最初は 00:00、3つ以上を昇順、1チャプターは最短10秒。 【一次】[S1]
- 手動のチャプターを付けると自動生成は無効になる。自動生成は新しい動画では既定でオン。 【一次】[S1]
- 違反警告があるチャンネルや一部の視聴者に不適切なコンテンツでは、チャプター機能は使えない。 【一次】[S1]
- 機能の一覧表（クリエイター向け機能のヘルプ、2026-11-19 取得の日英）では、チャプターの追加、動画と投稿へのコメントの固定、ショートへの関連動画の追加は上級者向け機能に入っている。チャプターのヘルプも、使えない場合は上級者向け機能へのアクセス権を申請するよう案内している。 【一次】[S1][S11][S12]
- 終了画面は動画の最後の5〜20秒に付けられ、動画の長さが25秒以上必要。16:9 なら最大4要素。 【一次】[S2]
- 終了画面は子ども向けの動画、YouTube Music アプリ、モバイルウェブ（iPad を除く）、360° 動画などでは表示されず、視聴者が非表示にもできる。 【一次】[S2]
- YouTube は編集時に最後の20秒を終了画面用に空けるよう勧めている。 【一次】[S2]
- 情報カードは1本に最大5枚。動画・再生リスト・チャンネル・リンク（YPP 参加者のみ）を載せられる。子ども向けの動画では使えない。 【一次】[S3]
- Content ID の申し立てを受け、コンテンツ所有者がキャンペーンを設定している動画ではカードが表示されない。 【一次】[S3]
- ショートには関連動画を1つ設定でき、チャンネル ハンドルの下にクリックできるリンクとして出る。設定には上級者向け機能へのアクセスが必要。 【一次】[S4]
- ショートのコメントと説明に書いた URL はクリックできない。長尺のコメント・説明でクリックできる外部リンクを付けるには上級者向け機能の有効化が必要。 【一次】[S5]
- 固定コメントは、Studio の [コミュニティ] で個々の動画のコメントを確認しているときに、その他アイコン → [固定] で動画再生ページの上部に固定する。 【一次】[S6]

## 詳細

### チャプター
チャプターは動画を複数のセクションに分ける機能で、チャプターごとにプレビューが表示される。手動で付けるか、自動生成を使う。文字起こしにチャプターが表示されることもある。 【一次】[S1]

手動で付ける条件: 【一次】[S1]

| 条件 | 確度・出典 |
|---|---|
| 説明欄にタイムスタンプとタイトルのリストを書く | 【一次】[S1] |
| 最初のタイムスタンプは 00:00 | 【一次】[S1] |
| タイムスタンプは3つ以上、昇順 | 【一次】[S1] |
| チャプターの最短の長さは10秒 | 【一次】[S1] |

> 「リストの最初のタイムスタンプは 00:00 で始まるようにします。」[S1]
> 「3 つ以上のタイムスタンプを昇順でリストする必要があります。」[S1]
> 「動画チャプターの最短の長さは 10 秒です。」[S1]

- 手動のチャプターを保存すると、その動画のチャプターの自動生成は無効になる。 【一次】[S1]
- チャプター機能を使えない場合は、上級者向け機能へのアクセス権を申請するよう案内されている。 【一次】[S1]
> 「注: チャプター機能を利用できない場合は、上級者向け機能へのアクセス権を申請してください。」[S1]
- 上の書式の条件とは別に、機能の一覧表ではチャプターの追加が上級者向け機能に分類されている（英語版の表でも Advanced の下に Add chapters がある）。チャプターのヘルプ（[S1]）の本文は、上級者向け機能を条件としては書いておらず、使えない場合の申請先として書いている。上級者向け機能を得る条件は [../channel/新規チャンネルの立ち上げ.md](../channel/新規チャンネルの立ち上げ.md) を参照。 【一次】[S1][S11][S12]
> 「チャプターの追加」[S11]
- 自動生成: Studio の動画の編集画面で [すべて表示] → [チャプターの自動生成] → [チャプターの自動生成を行う] をオン。新しくアップロードする動画では既定でオンで、一括でオン・オフもできる。チャンネル全体の既定は [アップロード動画のデフォルト設定] → [詳細設定] で変える。 【一次】[S1]
> 「違反警告があるチャンネルや、一部の視聴者に対して不適切なコンテンツの場合、動画チャプター機能は利用できません。」[S1]
- 自動生成を使える動画でも、チャプターが生成されないことがある。 【一次】[S1]

### 終了画面
> 「終了画面は動画の最後の 5～20 秒に追加でき、他の動画を宣伝したり、視聴者にチャンネル登録を促したりできます。」[S2]
> 「終了画面を表示するには動画の長さが 25 秒以上必要です。」[S2]

- 16:9 の動画では最大4要素。他のアスペクト比では少なくなる可能性がある。 【一次】[S2]
- 終了画面の間は、カードのティーザーや動画の透かしなどの他のインタラクティブ要素は非表示になる。 【一次】[S2]
- 視聴者は視聴中に終了画面を非表示にできる。 【一次】[S2]
- 要素が複数ある場合、既定ではすべて同時に表示され、要素ごとに表示のタイミングを変えられる。 【一次】[S2]
- 終了画面は常に表示されるとは限らず、パフォーマンス・視聴者の行動・デバイス・コンテキストに基づいて設定と違う表示になることがある。 【一次】[S2]

追加できる要素: 【一次】[S2]

| 要素 | 内容 | 確度・出典 |
|---|---|---|
| 動画 | 最新のアップロード、視聴者に適した動画（チャンネルから自動選択）、特定の動画（自分または他のチャンネルの公開・限定公開の動画） | 【一次】[S2] |
| 再生リスト | 公開されている再生リスト（限定公開も選べるとの記述あり） | 【一次】[S2] |
| チャンネル登録 | チャンネル登録を促す | 【一次】[S2] |
| チャンネル | カスタム メッセージで別のチャンネルを宣伝 | 【一次】[S2] |
| リンク | YPP 参加クリエイターのみ、外部ウェブサイトへのリンク | 【一次】[S2] |
| 商品 | 商品をタグ付けして紹介 | 【一次】[S2] |
| テンプレート | カスタマイズできる要素のグループ | 【一次】[S2] |

表示されない環境（視聴者側）: 【一次】[S2]
- モバイルウェブ（iPad 向けモバイルウェブを除く）
- YouTube Music アプリ、YouTube Kids アプリ
- Flash 動画、360° 動画
- 子ども向けに設定した動画。前に終了画面を追加していても、子ども向けにすると表示されなくなる（[子ども向け設定.md](子ども向け設定.md)）。 【一次】[S2][S8]

YouTube が挙げるおすすめの作り方: 【一次】[S2]
- 動画と関連性のある要素を表示する。
- 行動を促すフレーズで、要素をクリックするよう促す。
- カスタム画像は 300 x 300 ピクセル以上を推奨。
- 要素ごとに表示のタイミングをずらす。
> 「動画を編集するときに、最後の 20 秒を使えるよう配慮してください。」[S2]

効果の確認: YouTube アナリティクスの [エンゲージメント] タブで、動画ごとの [終了画面要素のクリック率]、チャンネル全体の [人気の終了画面要素の種類] と [終了画面で人気の動画] を見られる（指標全般は [アナリティクス指標.md](アナリティクス指標.md)）。 【一次】[S2]

外部リンクの注意: リンク先がコミュニティ ガイドラインと利用規約に準拠していない場合、カードやリンクの削除、違反警告、Google アカウントの停止などの措置がありうる。 【一次】[S2][S3]

### 情報カード
- 情報カードには動画・再生リスト・チャンネル・リンクを載せられる。 【一次】[S3]
> 「注: 1 本の動画に最大 5 枚までカードを追加できます。」[S3]
- 動画・再生リストのカードは YouTube の公開動画・公開再生リストへのリンク。 【一次】[S3]
- リンクのカードは YouTube パートナー プログラム参加者のみ使える。 【一次】[S3]
- チャンネルのカードにはメッセージとティーザー テキストが必須。 【一次】[S3]
- 追加は Studio の [コンテンツ] → 動画 → [エディタ] → [情報カード]。タイムラインで表示開始時間を調整する。 【一次】[S3]
- 視聴者には指定したタイミングでティーザーが出る。出ていないときはプレーヤーのカードアイコンから見られ、モバイルではコントロール バーが出ている間にアイコンが出る。 【一次】[S3]
- カードは動画の説明の下に表示され、複数あれば再生中にスクロールできる。 【一次】[S3]
- YouTube は、パフォーマンス・視聴者の行動・デバイスに基づいて関連性の高いティーザーが出るよう改良していく予定、と書いている。 【一次】[S3]
> 「動画が Content ID による申し立てを受け、そのコンテンツ所有者によってキャンペーンが設定されている場合、動画にカードは表示されません。」[S3]
- カードを表示する動画には Call-to-Action オーバーレイが表示されない。 【一次】[S3]
- 子ども向けに設定した動画ではカードを表示できない。 【一次】[S3][S8]
- ヘルプのパソコン版には次の記述がある。 【一次】[S3]
> 「この機能は、パソコンでご利用いただけます。」[S3]

### 固定コメント
- パソコンの Studio では、[コミュニティ] の [公開済み] タブで、その他アイコン → [固定] を選ぶと、コメントが動画再生ページの上部に固定される。このオプションは個々の動画のコメントを確認しているときにだけ表示される。Android 版のヘルプも同じ手順（コメントをタップ → その他アイコン → [固定]）。 【一次】[S6][S10]
- 機能の一覧表では、コメントの固定は上級者向け機能に分類されている（英語版の表では Pin comments on videos and posts）。固定の手順のヘルプ（[S6][S10]）の本文には、上級者向け機能の記述はない。 【一次】[S11][S12]
> 「動画と投稿へのコメントの固定」[S11]
- 1本に固定できる数、置き換え、固定できる人（所有者・モデレーター）は、読んだヘルプの本文になかった（『わかっていないこと・要確認』の節を参照）。
- スマートテレビやゲーム機のコメント パネルにも、クリエイターが固定したコメントが表示される。 【一次】[S7]

### ショートの関連動画
> 「関連動画を追加すると、YouTube ショート プレーヤーで自分の動画、ショート動画、ライブ配信を紹介できます。」[S4]
- 追加はショートのアップロード後、Studio の [コンテンツ] → ショートを選ぶ → チャンネルの [関連動画] を選ぶ → [保存]。 【一次】[S4]
> 「関連動画を追加できるのは、上級者向け機能にアクセスできるユーザーのみです。」[S4]
- 機能の一覧表でも、ショートへの関連動画の追加は上級者向け機能に入っている。 【一次】[S11][S12]
- 選ぶ動画は公開または限定公開で、コミュニティ ガイドラインに準拠している必要がある。 【一次】[S4]
- 視聴者にはチャンネル ハンドルの下にクリックできるリンクとして表示される。 【一次】[S4]
- 自分の公開済みの長尺動画からショートを作る機能（英語版の表記で Remix → Edit into a Short）では、作ったショートは元の動画にリンクされる、と英語版ヘルプ（Android 版）は書いている（訳）。 【一次】[S9]
> 「Shorts you create from your videos are linked back to your original video」[S9]
- ショートの他の仕様は [ショートの仕様.md](ショートの仕様.md) を参照。

### クリックできるリンクの範囲
> 「注: スパムや詐欺行為を減らすため、ショート動画のコメントやショート動画の説明に記載されている URL はクリックできません。」[S5]
- 一覧表のうち、長尺動画のコメントや説明の URL と、投稿のリンクには注記があり、クリックできる外部リンクを付けるにはチャンネルで上級者向け機能を有効にする必要がある。 【一次】[S5]
> 「クリック可能な外部リンクを追加するには、チャンネルで上級者向け機能の利用を有効にする必要があります。」[S5]
- チャンネル プロフィールには最大14件のリンクを表示できる。 【一次】[S5]
- 一覧表には、ショート動画からリンクされた関連動画と終了画面も項目として載っている（取得したテキストでは表の可否の記号が読めなかった）。 【一次】[S5]

### 上級者向け機能が関わるもの（このファイルの範囲）
上級者向け機能のアクセスが条件として書かれているのは、チャプターが使えない場合の申請、ショートの関連動画、長尺のコメント・説明・投稿のクリックできる外部リンク。 【一次】[S1][S4][S5]
機能の一覧表で上級者向け機能に分類されているもののうち、このファイルの範囲のものは、チャプターの追加、動画と投稿へのコメントの固定、ショートへの関連動画の追加、長尺動画の説明と投稿へのクリック可能なリンクの追加。 【一次】[S11][S12]
上級者向け機能の取得条件そのものは [../channel/新規チャンネルの立ち上げ.md](../channel/新規チャンネルの立ち上げ.md) の範囲。

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。
- Remotion の構成データから説明欄のチャプター一覧を自動で書き出し、00:00 始まり・3つ以上・昇順・各10秒以上を書き出し時に検査する。長尺8〜12分なら、導入・仮説・実験・結果・解説などの節をそのままチャプターにできる。 （根拠: [S1]）
- 新しいチャンネルの初投稿の時点では、上級者向け機能がまだ付いていない前提にする。チャプターと固定コメントは一覧表で上級者向け機能なので、付くまではチャプターや固定コメントがなくても成り立つ説明欄・構成にする。初投稿の前に身分証明書か動画による本人確認を試し、通れば最初から使う（取得の条件は [../channel/新規チャンネルの立ち上げ.md](../channel/新規チャンネルの立ち上げ.md)）。 （根拠: [S1][S11][S12]）
- 長尺のテンプレートでは最後の20秒を終了画面用に空け、16:9 で4要素ぶんの余白（次の動画・再生リスト・チャンネル登録）をレイアウトに組み込む。 （根拠: [S2]）
- 終了画面は環境によって出ないので、次の動画への誘導は終了画面だけに頼らず、2人の掛け合いの台詞でも言う。 （根拠: [S2]）
- 開設したらすぐに上級者向け機能を有効にする。チャプター、コメントの固定、ショートの関連動画、説明欄のクリックできるリンクに関わるため。 （根拠: [S1][S4][S5][S11]）
- 上級者向け機能が付いたら、ショートには同じ実験を詳しく扱う長尺を関連動画に設定する。ショートの説明欄に URL を書いてもクリックできないため。付くまでは、長尺への誘導を映像と台詞で入れる。 （根拠: [S4][S5][S11]）
- 情報カードは本編中で過去の実験に触れる場面に置く（最大5枚）。BGM などに申し立てがありキャンペーンが設定されるとカードが出なくなるので、申し立てを解消してから公開する。 （根拠: [S3]、[著作権とContent_ID.md](著作権とContent_ID.md)）
- 終了画面のクリック率を動画ごとに記録し、要素の種類や配置を比べる。 （根拠: [S2]）

## わかっていないこと・要確認
- 固定コメントの条件は、検索要約では次のようにされているが、読んだヘルプ（[S6][S10]、answer/15535966）の本文では確認できなかった。 【未確認】（検索要約のみ・原文未読）
  - 1本に固定できるのは1つで、新しく固定すると前のものと置き換わり、解除すると元の位置に戻る。
  - 自分のコメントもファンのコメントも固定できるが、上級者向け機能へのアクセスが必要で、有効化から反映まで最長24時間かかる場合がある。
    - （2026-11-20 追記）このうち、コメントの固定が上級者向け機能であることは、機能の一覧表 [S11][S12] で確かめた（詳細の『固定コメント』の節）。自分・ファンのどちらのコメントも固定できること、反映まで最長24時間は、引き続き未確認。
  - 固定・固定解除はチャンネル所有者だけができ、管理モデレーター・標準モデレーターにはその権限がない（answer/15535966 の取得テキストには権限の表が出なかった）。
- 自分の長尺からショートを作ったとき、元の動画がショートの [関連動画] として自動で設定されるのか、別の形のリンクなのか、また非公開・限定公開・子ども向けのショートでは追加されないという条件は、検索要約のみで、読んだ英語版ヘルプ（[S9]）の本文にはない。 【未確認】
- ショートの関連動画を設定したときと、しないときの効果（クリック率など）の公式の数値は、今回の資料にない。
- 自動チャプターがどの言語・どの長さの動画で生成されやすいかの条件は公開されていない（今回の資料に記述なし）。
- 終了画面の要素数が16:9以外（縦型など）でいくつになるかの具体的な数は、ヘルプに書かれていない。
- クリックできるリンクの一覧表の、各項目のクリック可・不可の記号は取得したテキストで読めなかった。ブラウザで確認する。
