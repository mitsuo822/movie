# 画面録画とエンコード（OBS Studio・NVENC）

> 対象: 画面録画ソフト OBS Studio の録画設定（簡易モードの録画品質と CQP の対応、詳細モードの NVENC の項目、録画形式とクラッシュ時の復元）、制作 PC の GPU（RTX 4070 Ti SUPER）の NVENC の仕様、OBS に縦のキャンバスを足すプラグイン。どのゲーム・ソフトの画面録画にも共通する部分を扱い、Minecraft のゲーム内の設定と Replay Mod・Flashback との使い分けは minecraft_physics リポジトリの [録画設定.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/filming/録画設定.md) に、MC の縦の撮り方は [縦型撮影.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/filming/縦型撮影.md) に任せる。
> 使う場面: OBS の録画プロファイルを作るとき。録画形式・コーデックを決めるとき。ショート用の縦の録画を OBS で作るか検討するとき。

## 要点
- OBS の簡易モードの録画品質「Indistinguishable Quality, Large File Size」は、NVENC では CQP 16（出力の対角が 2000px 以上の場合。それより小さい解像度では値が下がる）、「High Quality, Medium File Size」は CQP 23 を基準にする。ソースコードで確認。【一次】[S2][S3]
- 簡易モードで Lossless を選ぶと AVI（utvideo＋pcm_s16le）で書き出す。OBS は、高い解像度とフレームレートでは1分あたり 7GB を超えることがあり、リプレイバッファも使えないと警告する。【一次】[S2][S3]
- OBS の NVENC のレート制御は CBR / VBR / CQVBR / CQP / Lossless、プリセットは P1〜P7。【一次】[S1]
- OBS は、MP4/MOV は書き終えられないと復元できない、と警告する。録画形式は MKV、MP4、MOV、Hybrid MP4/MOV、Fragmented MP4/MOV などが選べ、チャプターマーカーは Hybrid MP4/MOV だけ。【一次】[S2]
- Fragmented MP4/MOV は、ディスクへの書き込みが途中で切れても再生できる形式と説明されるが、すべてのプレーヤー・編集ソフトで使えるとは限らないとも書かれている。【一次】[S2]
- RTX 4070 Ti SUPER は AD103（Ada Lovelace 世代、第8世代 NVENC）で、AD103 は NVENC を2基持つ。第8世代は AV1 と HEVC で 10bit、H.264 は 8bit まで。【二次】[S4][S5]
- 第8世代 NVENC の AV1 の性能は、Wikipedia の2つの記事で書き方が違う（60FPS と 120FPS）。【二次】[S4][S5]
- OBS に縦のキャンバスを足すプラグイン『Vertical Canvas for OBS Studio』（Aitum）がある。機能の詳細は README になく、配布ページは検索要約しか得られていない。【一次】[S7]

## 詳細

### OBS: 簡易モードの録画品質（ソースコードで確認）
- 簡易モードのエンコーダの選択肢に「Hardware (NVENC, H.264)」「Hardware (NVENC, HEVC)」「Hardware (NVENC, AV1)」がある。【一次】[S2]
- 録画品質の選択肢: 「Same as stream」「High Quality, Medium File Size」「Indistinguishable Quality, Large File Size」「Lossless Quality, Tremendously Large File Size」。【一次】[S2]
- 品質と数値の対応はソースの `int crf = CalcCRF(ultra_hq ? 16 : 23);` で、HQ（Indistinguishable）なら 16、それ以外なら 23 を基準にする。NVENC の場合、この値を CQP としてそのまま使い、H.264 は profile high、HEVC と AV1 は profile main。【一次】[S3]
- `CalcCRF` は、出力解像度の対角が 2000px 未満だと値を最大 10 下げる（＝高画質寄りにする）。ソースから計算すると 1920×1080（対角約 2203px）では下がらず 16、1280×720（対角約 1469px）では 14 になる。x264 の低CPU用プリセットのときだけ、さらに 2 下げる処理がある。【一次】[S3]
- Lossless を選ぶと、AVI に utvideo（映像）と pcm_s16le（音声）で書き出す: 「obs_data_set_string(settings, "video_encoder", "utvideo");」【一次】[S3]
- Lossless の警告文: 「Lossless quality can use upward of 7 gigabytes of disk space per minute at high resolutions and framerates.」「Replay buffer is unavailable when using lossless quality.」【一次】[S2]
- キャンバスと出力の解像度は別物: 「The canvas (base) resolution is not necessarily the same as the resolution you will stream or record with.」【一次】[S2]

| Preset | 「P1: Fastest (Lowest Quality)」〜「P7: Slowest (Best Quality)」の7段階 | 【一次】[S1] |
| Tuning | 「Ultra High Quality (slow, not recommended)」、High Quality、Low Latency、Ultra Low Latency | 【一次】[S1] |
| Multipass Mode | Single Pass、「Two Passes (Quarter Resolution)」、「Two Passes (Full Resolution)」 | 【一次】[S1] |
| Look-ahead | 「it will increase visual quality by determining a better bitrate distribution through analysis of future frames」（GPU 使用率と遅延が増える） | 【一次】[S1] |
| Adaptive Quantization | 「especially in situations with high motion, at the cost of increased GPU utilization」（旧名 Psycho-Visual Tuning） | 【一次】[S1] |

- NVENC を同時に使う他のソフトについての文言: 「Try closing other recording software that might be using NVENC such as NVIDIA ShadowPlay or Windows Game DVR.」【一次】[S1]
- 10bit の入力形式について: 「NVENC does not support I010. Use P010 instead.」【一次】[S1]

### OBS: 録画形式
- 選べる形式: 「Matroska Video (.mkv)」「MPEG-4 (.mp4)」「QuickTime (.mov)」「Hybrid MP4 (.mp4)」「Hybrid MOV (.mov)」「Fragmented MP4 (.mp4)」「Fragmented MOV (.mov)」のほか FLV、MPEG-TS、HLS。【一次】[S2]
- MP4/MOV の警告: 「Recordings saved to MP4/MOV will be unrecoverable if the file cannot be finalized (e.g. as a result of BSODs, power losses, etc.).」「If you want to record multiple audio tracks consider using MKV and remux the recording to MP4/MOV after it is finished」【一次】[S2]
- Fragmented MP4/MOV の説明: 「This ensures the file remains playable even if writing to disk is interrupted, for example, as a result of a BSOD or power loss.」。ただし「This may not be compatible with all players and editors.」【一次】[S2]
- チャプターマーカーは Hybrid 形式だけ: 「Add Chapter Marker (Hybrid MP4/MOV only)」【一次】[S2]
- 録画後の変換: メニューの Remux Recordings と、詳細設定の「Automatically remux to %1」（MKV で録って自動で変換する）がある。【一次】[S2]

### GPU: RTX 4070 Ti SUPER の NVENC
- RTX 4070 Ti Super は 2024-01-24 発売、チップは AD103-275、メモリ 16 GB（wiki の表）。【二次】[S5]
- RTX 40 系は第8世代 NVENC で、「with high-end cards using 2 encoders」。【二次】[S5]
- NVENC の世代表（第8世代 Ada）: NVENC の数は AD107 / AD106 / AD104-250 が 1、AD104-400 / AD103 / AD102 が 2。【二次】[S4]
- 第8世代の対応: H.264 は 4:2:0 と 4:4:4、ロスレス可、最大 4096×4096、8bit。HEVC は 4:2:0 と 4:4:4、ロスレス可、最大 8192×8192、10bit、B フレーム可。AV1 は 4:2:0、最大 8192×8192、10bit。H.264 と HEVC の 4:2:2 は非対応（AV1 の列は 4:2:0 だけで、4:2:2 の欄がない）。【二次】[S4]
- 4:2:2 と AV1 の Ultra High Quality モードは次の Blackwell（第9世代）で入った、と wiki は書く（この段落の末尾に要出典タグが付いている）。【二次】[S4]
- AV1 の性能の書き方が2つの wiki で違う: NVENC の記事は「8K 10-bit 60FPS AV1 fixed function hardware encoder」、RTX 40 の記事は Dual NVENC の項目として「8K 10-bit 120FPS」と書く。どちらが正しいか、違いの理由は記事からはわからない。【二次】[S4][S5]
- 同時エンコード数の制限（GeForce）: 「From January 2024 onwards, eight simultaneous encoding video streams became the baseline.」「From November 2025 onwards, twelve simultaneous encoding video streams became the baseline.」【二次】[S4]
- OBS でのリアルタイム録画と、MC の Replay Mod・Flashback の書き出しの比較（録画中の負荷を含む）は minecraft_physics の [録画設定.md](https://github.com/mitsuo822/minecraft_physics/blob/main/knowledge/filming/録画設定.md) で扱う。

### 個人の設定例（参考・1件のみ）
- 2026-01-16 公開の note 記事（OBS Ver32.0.0、1080p60 で YouTube 配信する人向け）は、録画の変更後の設定として NVENC H.264、12000kbps、キーフレーム 2s、P5 Slow、2パス、Look-ahead ON を挙げ、「※ 録画は遅延を気にしなくてよいため品質優先」と書いている。変更前のエンコーダ名は「NVIDIA NVENC H.264（非推奨）」と表記されている。個人の経験に基づく設定で、比較の根拠は示されていない。【二次】[S6]

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。
- OBS の録画の出発点: 簡易モードの「Indistinguishable Quality」＋ NVENC（CQP 16 相当）で撮る。詳細モードにするなら Rate Control を CQP にし、プリセットは P5〜P7 から実測で選ぶ。（根拠: [S1][S2][S3]）
- 録画形式は、クラッシュ時に壊れないことを優先して MKV（自動リマックス）か Fragmented MP4 にする。編集ソフト（Remotion）で読めるかは最初に確かめる。（根拠: [S2]）
- コーデックは、まず H.264 で編集の流れを通し、ファイルサイズが問題になったら HEVC / AV1（10bit 可）を試す。（根拠: [S4][S5]）

## わかっていないこと・要確認
- OBS の master ブランチの文言・処理が、2026-11 時点のどのリリース版（32.x など）に当たるか。Hybrid MP4 が入った版。
- Hybrid MP4 の利点（Fragmented MP4 との違い）の公式の説明。今回読めた文言には説明がなかった。
- RTX 4070 Ti SUPER で OBS の Split Encode（2基の NVENC を使う）が使えるか、画質・速度にどう効くか。Tuning の「Ultra High Quality」が Ada で使えるか。
- 第8世代 NVENC の AV1 の性能（60FPS か 120FPS か。RTX 40 の記事の 120FPS が2基の合計かどうか）。NVIDIA の一次資料は未読。
- Aitum の縦キャンバスのプラグインの現行版の機能と、必要な OBS のバージョン。以下は OBS フォーラムの配布ページなどの検索要約のみ（原文未読）で、事実として扱わない。【未確認】[S8]
  - 通常のキャンバスとは別のキャンバスで縦の内容を扱い、通常のシーンと縦のシーンを連動させる。
  - 縦のキャンバスに専用の配信・録画の設定がある。
  - 1.3.0 で縦キャンバスの複数出力に対応した。
  - 1.6.4 の変更履歴では OBS 31.1 以上が必要とされている（配布ページの最小バージョンの表示は 29.0.0 で、食い違う）。
