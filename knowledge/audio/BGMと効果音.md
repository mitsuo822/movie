# BGMと効果音

> 対象: 動画に使うBGM・効果音の入手先と利用条件（YouTube オーディオ ライブラリ、クリエイター ミュージック、DOVA-SYNDROME（現 OpenTracks）、魔王魂、効果音ラボ、OtoLogic）、フリー素材が Content ID の申し立てを受ける問題、市販曲と JASRAC の許諾の範囲、効果音の入れ方の実例。
> 使う場面: 企画〜編集でBGM・効果音を選ぶとき、投稿前に素材の権利を確認するとき、Content ID の申し立てを受けたとき。
> 調査日: 2026-11-19 ／ mc_version: —（MCに依存しない）
> 関連: [音量とラウドネス.md](./音量とラウドネス.md), [VOICEVOX利用規約.md](./VOICEVOX利用規約.md), [../youtube/著作権とContent_ID.md](../youtube/著作権とContent_ID.md), [../youtube/ショートの仕様.md](../youtube/ショートの仕様.md), [../youtube/収益化の条件.md](../youtube/収益化の条件.md)

## 要点
- YouTube が著作権上問題ないと認めている音源は、YouTube オーディオ ライブラリの音楽と効果音だけ。そこからダウンロードした音源には Content ID の申し立てが来ない、と公式ヘルプに明記されている。 【一次】[S1]
- オーディオ ライブラリでもクリエイティブ・コモンズの曲は、説明欄にクレジットが必要。「帰属表示が不要」のフィルタで、クレジット不要の曲だけを探せる。 【一次】[S1]
- 外部サイトで「無料」とされている音楽でも Content ID の申し立てを受けることがあり、説明欄に「無料の曲」と書いても考慮されない、と公式ヘルプに書かれている。 【一次】[S2]
- ショート（60秒未満）で問題のない音楽でも長尺では使えない場合があるため、長尺ではオーディオ ライブラリなど安全な入手先に限るよう公式が勧めている。 【一次】[S2]
- クリエイター ミュージック（YouTube Studio 内の音楽カタログ）は、2026-11-19 時点のヘルプでは YPP に参加している米国のクリエイターだけが使える。米国外への拡大は保留中。日本のチャンネルは使えない。 【一次】[S3]
- DOVA-SYNDROME は 2026-03-01 に株式会社TRACKS が運営を引き継ぎ、2026-09-15 に OpenTracks に名称が変わった。 【二次】[S7]
- OpenTracks の公式ヘルプでは、YouTube 上の著作権管理は TRACKS Inc. が行っていて、TRACKS Inc. が申し立てた動画は禁止事項や作曲者ごとの条件に違反している可能性がある、と書かれている（検索要約のみ・原文未読）。 【未確認】[S8]
- 魔王魂は、BGM・効果音などを CC BY 4.0（著作権表示を条件に改変・商用利用を許諾）で公開している、と Wikipedia に書かれている（出典の閲覧日は 2022-12-08）。現在の規約は未確認。 【二次】[S10]
- JASRAC が YouTube に出している許諾は、JASRAC が管理する「楽曲」の利用が対象。JASRAC が管理するのは作詞者・作曲者・音楽出版者から預かった著作権で、原盤権（レコード製作者の権利＝著作隣接権）は楽曲の著作権とは別の権利。 【一次】[S4] 【二次】[S5][S6]
- そのため、市販CDの音源をそのまま使うには原盤権を持つレコード会社の許諾が別に必要、という説明がある（検索要約のみ・原文未読）。 【未確認】[S14]
- 効果音を鳴らす場所を、図解が出た瞬間・話のかたまり（章）の切り替わり・結論や数字を出す瞬間の3か所に絞る運用を、10〜12分の解説動画6本の実測値（1分あたり中央値6.5回）付きで公開している個人の実例がある。 【二次】[S12]

## 詳細

### YouTube オーディオ ライブラリ（2026-11-19 時点のヘルプ）
YouTube Studio のオーディオ ライブラリには、著作権使用料無料の音楽と効果音がある。 【一次】[S1]
> 「YouTube Studio のオーディオ ライブラリには、動画で使用できる著作権使用料無料のプロダクション ミュージックと効果音が用意されています。」[S1]

- 開き方: YouTube Studio の左メニュー［オーディオ ライブラリ］。youtube.com/audiolibrary から直接開くこともできる。 【一次】[S1]
- 音楽はジャンル、ムード、ボーカル、BPM、時間（秒）、帰属情報で絞り込める。効果音はカテゴリと時間（秒）で絞り込める。 【一次】[S1]
- 新曲の追加は月に2回。 【一次】[S1]
  > 「オーディオ ライブラリには、新曲が 1 か月に 2 回の頻度で追加されます。」[S1]
- ダウンロード形式は MP3。ダウンロード時にライセンスの確認が表示される。 【一次】[S1]
- クリエイティブ・コモンズの曲は、説明欄でのクレジットが必須。クレジット文はライブラリの［ライセンス タイプ］列のアイコンからコピーできる。 【一次】[S1]
  > 「クリエイティブ・コモンズ ライセンスが適用されたトラックを使用する場合は、必ず動画の説明欄でアーティストのクレジットを表記してください。」[S1]
- ライブラリの曲を使った動画の再生ページには、「この動画の音楽」の欄が表示される。 【一次】[S1]
- YPP に参加していれば、ライブラリの音楽と効果音を使った動画を収益化できる。 【一次】[S1]
  > 「YouTube パートナー プログラムに参加している場合は、オーディオ ライブラリの音楽と効果音を使用して動画を収益化できます。」[S1]
- Content ID の申し立てが来ないこと、YouTube が安全と認めているのはライブラリの音源だけであることが明記されている。 【一次】[S1]
  > 「オーディオ ライブラリからダウンロードした著作権上問題のない音楽または効果音に対して、権利所有者から Content ID システムによる申し立てを受けることはありません。」[S1]
  > 「YouTube が著作権上問題ないと認識しているのは、オーディオ ライブラリの音楽と効果音のみです。」[S1]
- 他の音楽ライブラリの著作権使用料無料の音源で問題が起きても、YouTube は責任を負わない。法的なガイダンスは出せないので、不明な点は弁護士に相談するよう勧めている。 【一次】[S1]
  > 「の音楽や効果音によって生じた問題に対して責任を負いません。」[S1]
- 日本語版ヘルプには、AI による翻訳が含まれる場合があるという注記がある。条件を厳密に確かめるときは英語版も読むこと。 【一次】[S1]

### 外部の「無料」音楽と Content ID（公式ヘルプ『著作権上問題のない音楽を見つけるためのヒント』）
- 著作権上問題のない音楽とは、パブリック ドメインの音楽か、著作権者から使用許可を得た音楽のこと。 【一次】[S2]
- ネットで「無料」とされている音楽でも、Content ID に報告されることがある。 【一次】[S2]
  > 「Content ID によって報告されることがあります。これにより、公開設定と収益の制限が生じる可能性があります。」[S2]
- 説明欄に「無料の曲」と書いても、Content ID はそれを考慮しない。 【一次】[S2]
  > 「の音楽に関する説明文は考慮されません。」[S2]
- 他のサイトやオフラインで権利を買ったかどうかも、Content ID は把握していない。 【一次】[S2]
  > 「また、Content ID は、お客様が音楽の権利を他のウェブサイトやオフラインで購入したかどうかを把握していません。」[S2]
- 公式が勧める入手先: ①オーディオ ライブラリ、②自作の音楽、③クリエイター ミュージック、④サードパーティのロイヤリティフリー・有料音楽（ライセンスを必ず確認する）。 【一次】[S2]
  > 「ただし、選択する前に必ずミュージック ライセンスを確認してください。」[S2]
- ショートと長尺の違い: 【一次】[S2]
  > 「60 秒未満のショート動画で使用しても問題ない音楽でも、長尺動画では使用できない場合があります。」[S2]
  > 「長尺動画で使用する場合は、YouTube オーディオ ライブラリやクリエイター ミュージックなど、安全なリソースに限定してください。」[S2]
- 申し立ての種類、異議申し立ての手順、収益への影響は [../youtube/著作権とContent_ID.md](../youtube/著作権とContent_ID.md) で扱う。

### クリエイター ミュージック（日本からは使えない）
- 2026-11-19 時点のヘルプでは、使えるのは YPP に参加している米国のクリエイターだけ。 【一次】[S3]
  > 「クリエイター ミュージックは現在、YouTube パートナー プログラム（YPP）に参加している米国のクリエイターにご利用いただけます。」[S3]
  > 「YPP にご参加の米国以外のクリエイターへの拡大は保留されています。」[S3]
- ライセンスは動画1本ごとの1回限り。同じ曲を複数の動画で使うなら、動画ごとにライセンスが要る。 【一次】[S3]
  > 「トラックのライセンスを 1 つ取得した場合、そのトラックを使用できるのは 1 本の動画のみということです。」[S3]
- クリエイター ミュージックの収益分配は長尺動画で曲を使うときの仕組みで、ショートの収益分配とは別のもの。 【一次】[S3]
- 公式ヘルプ（S2）は入手先の候補としてクリエイター ミュージックを挙げているが、日本のチャンネルは対象外なので、実際に使えるのはオーディオ ライブラリになる。 【一次】[S2][S3]

### DOVA-SYNDROME（現 OpenTracks）
- 2009年に作曲家の稿屋隆が開設した。2026-03-01 に株式会社TRACKS が運営を引き継ぎ、2026-09-15 に名称を OpenTracks に変更した。 【二次】[S7]
- 曲数は、2025年時点でBGM・ジングルが約18,700曲、効果音が約1,300音。 【二次】[S7]
- 公開曲はすべて無料。規約はサイト全体のものに加えて、作曲者ごとの利用規約がある曲もある。 【二次】[S7]
- Wikipedia（2026-11-09 閲覧の出典あり）には、株式会社TRACKS が12月1日から有料のメンバーシップを始めると発表した、とある。何年の12月か、無料の範囲が変わるかは本文からは読み取れない。 【二次】[S7]
- **YouTube での扱い（Content ID 関連）**: OpenTracks の英語版ヘルプ『Using on YouTube』の検索要約によれば、サイトの音源の YouTube 上の著作権管理は TRACKS Inc. が行っている。TRACKS Inc. が申し立てた動画は、ライセンスの禁止事項や作曲者の利用条件に違反している可能性がある、という趣旨の記述がある（検索要約のみ・原文未読）。 【未確認】[S8]
- DOVA の作曲者のサイトには、問題がなければ YouTube で異議申し立てをしたうえで運営に問い合わせる、という Q&A がある（検索要約のみ・原文未読）。 【未確認】[S9]
- **読めなかったこと**: dova-s.jp の各ページは opentracks.com に 301 転送され、このセッションのプロキシでは opentracks.com が拒否された（2026-11-19）。そのため規約の本文（禁止事項、クレジットの要否、Content ID 登録曲の見分け方）は読めていない。

### 「フリー」の意味
- フリー音楽素材の「フリー」には「無料」と「著作権フリー」の2つの意味がある。無料の素材でも、著作権表記の義務などの制限があることが多い。 【二次】[S13]
- 音楽素材サイトごとに規約があり、著作権表記の義務、利用報告の義務、成人向け作品での使用禁止などの例がある。 【二次】[S13]

### 市販曲と JASRAC・YouTube の許諾の範囲
- JASRAC は YouTube と2008年10月に包括的利用許諾契約を結び、サイト収入の2.5%を著作権料として徴収している、と Wikipedia に書かれている（出典は2010年の朝日新聞）。 【二次】[S5]
- 2023-02-10、YouTube（Google）は JASRAC と新しい許諾契約を結んだと発表した。 【一次】[S4]
  > 「YouTube を運営する Google は、YouTube 上での 日本音楽著作権協会（JASRAC）管理楽曲の利用について、JASRAC と新たに許諾契約を締結しました。」[S4]
- この契約で JASRAC は、2023年時点で7500万を超える管理楽曲を対象に Content ID の本格的な活用を始めた。 【一次】[S4]
  > 「JASRAC は 2023 年現在 7500 万を超える JASRAC 管理楽曲を対象に、YouTube の自動コンテンツ識別システム Content ID の活用を本格的に開始します。」[S4]
- 許諾の範囲は、YouTube のサービス全般での「JASRAC 管理楽曲」の利用。ユーザーのオリジナル動画とショートを含む。 【一次】[S4]
  > 「JASRAC から YouTube が受けている許諾は、レコード会社等が制作するミュージックビデオ等の公式コンテンツにおける楽曲の利用や、ユーザーが作成するオリジナル動画における楽曲の利用に加え、YouTube ショートでのオーディオライブラリからの楽曲の利用を含む、現在の YouTube のサービス全般における JASRAC 管理楽曲の利用を対象としています。」[S4]
- JASRAC が管理するのは、作詞者・作曲者・音楽出版者から信託された楽曲・歌詞の著作権（複製権・演奏権など）。 【二次】[S5]
- 原盤権（録音・編集して完成した音源＝マスター音源に対する権利）は著作隣接権の一つ。日本の著作権法ではレコード製作者の権利（第96条〜第97条の3）にあたり、楽曲の著作権とは基本的に独立している。 【二次】[S6]
- 2018年の資料（個人作成で公式見解ではない、と検索要約に注記あり）には、JASRAC は著作隣接権（原盤権）を管理していないので、CDやダウンロード音源を使うにはレコード会社の許諾が必要、と書かれている（検索要約のみ・原文未読）。 【未確認】[S14]
- まとめ: 公式ブログ（S4）が示す許諾の対象は「楽曲」。市販音源を流すときに要る原盤の許諾がこの契約に含まれないことを、公式の文書で直接確かめたわけではない。原盤権が別の権利であること（S6）と検索要約（S14）からの理解にとどまる。

### 効果音の入れ方の実例（個人の運用、2026-08-07 公開の note）
- 筆者は、効果音を鳴らす場所を次の3か所に絞り、ほかでは鳴らさないと決めている。 【二次】[S12]
  > 「① 図解が画面に出た瞬間（図解1つにつき1回。中の項目が5つあっても1回）」[S12]
  - ② 話のかたまり（章）が切り替わるところ（1本で4〜6回程度）、③ 結論や数字を出す瞬間（1本で1〜2回）。 【二次】[S12]
- 鳴らさない場所: テロップが出るたび、カットがつながるたび、感情の演出（驚き・失敗・オチ）。 【二次】[S12]
- 理由として筆者は、合図が多すぎると合図として機能しなくなること、配布されている効果音は大きめに作られていることを挙げている（筆者の考え）。 【二次】[S12]
- 図解の表示から0.3秒遅らせて鳴らしている。 【二次】[S12]
  > 「図解が出てから0.3秒だけ遅らせて鳴らしています。」[S12]
- 筆者の直近6本（10〜12分の解説動画）を機械で数えた結果: 【二次】[S12]
  > 「効果音が鳴った合計：418回（6本）」[S12]
  > 「1分あたり：中央値 6.5回（いちばん少ない回で4.5回、多い回で7.9回）」[S12]
  - 鳴る間隔の中央値は9.2秒、最も詰まったところで2.2秒。音の長さは1.25秒で、前の音と重なった回数は0回。 【二次】[S12]
- これは1チャンネルの運用の記録で、視聴維持率などの効果を測ったものではない。効果音の音量（LUFS）の実測値は [音量とラウドネス.md](./音量とラウドネス.md) に書いた。

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。
- **長尺のBGM・効果音は YouTube オーディオ ライブラリを第一にする。** Content ID の申し立てが来ないと公式が明記している入手先はここだけで、日本のチャンネルはクリエイター ミュージックを使えない。（根拠: [S1][S2][S3]）
- **クレジット不要の曲だけを使う運用にすると楽。** ライブラリの「帰属表示が不要」フィルタを使う。CC の曲を使うときは、ライブラリからコピーしたクレジット文を説明欄のテンプレートに入れる。（根拠: [S1]）
- **外部サイトの素材は、規約を人が読んでから使う。** 動画ごとに素材名・サイト・規約のURL・確認日を記録し、申し立てを受けたときに異議申し立ての根拠を出せるようにする。特に OpenTracks（旧DOVA）は運営会社が YouTube 上の権利を管理していて、作曲者ごとの条件もある。（根拠: [S2][S7][S8]）
- **ショートで使えた音楽をそのまま長尺に流用しない。**（根拠: [S2]）
- **市販曲は使わない。** JASRAC の許諾は楽曲が対象で、原盤の扱いは公式文書で確かめられていない。物理の検証動画に市販曲は必要ない。（根拠: [S4][S6][S14]）
- **効果音は鳴らす場所の一覧を先に決める。** 例: 計測値・グラフが出た瞬間に1回、章の切り替えに1回、結論に1回。Remotion で組み立てるなら、この一覧をデータとして持ち、自動で配置できる。効果は自分たちのアナリティクスで確かめる。（根拠: [S12]）

## わかっていないこと・要確認
- OpenTracks（旧DOVA-SYNDROME）の現在の規約本文: YouTube の収益化の可否、クレジットの要否、Content ID の申し立てを受けたときの公式の手順、作曲者ごとの条件の見分け方、有料メンバーシップで無料の範囲が変わるか。opentracks.com がこの環境では読めない（403）ため、人がブラウザで確認する必要がある。
- 魔王魂の2026年時点の規約（CC BY 4.0 のままか、クレジットの書式）。Wikipedia の出典は2022年の閲覧。
- 効果音ラボ・OtoLogic の公式規約（クレジットの要否、YouTube での収益化、Content ID 登録の有無）。
- クリエイター ミュージックの有料ライセンスを2026年8月から段階的に終了する、という記述が検索要約に出たが、読んだヘルプ（S3）には見当たらず、どのページの記述か特定できていない。日本のチャンネルは対象外なので影響は小さい。
- 市販音源の原盤の許諾が YouTube と JASRAC の契約に含まれないことを、JASRAC の公式ページ（jasrac.or.jp、この環境では読めない）で確認すること。NexTone 管理楽曲の扱いも未調査。
- オーディオ ライブラリの曲を使っても誤った申し立てが来たという報告の有無と、その対処（M12 [../youtube/著作権とContent_ID.md](../youtube/著作権とContent_ID.md) で扱う範囲）。
