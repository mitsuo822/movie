# キャラクター立ち絵の規約

> 対象: VOICEVOX のキャラクターの「見た目」（公式イラスト、ファンが配布する立ち絵素材、3D・Live2D モデル、生成AIで作った画像）を動画・サムネイルに出すときの規約。声（音声ライブラリ）の規約とは別物で、声は [VOICEVOX利用規約.md](VOICEVOX利用規約.md) に書く。
> 使う場面: 掛け合いのキャラクターの見た目を決めるとき／立ち絵素材を選ぶとき／サムネイル・ショート・チャンネルのアイコンにキャラクターを出すとき／企業案件・メンバーシップを始めるとき。
> 調査日: 2026-11-19 ／ MCとは無関係（VOICEVOX の情報はエディタ 0.26.3 の時点）
> 関連: [VOICEVOX利用規約.md](VOICEVOX利用規約.md), [../script/掛け合い形式.md](../script/掛け合い形式.md), [../channel/AI音声チャンネルの事例とリスク.md](../channel/AI音声チャンネルの事例とリスク.md), [../planning/サムネイル.md](../planning/サムネイル.md), [../legal/ステルスマーケティング規制.md](../legal/ステルスマーケティング規制.md), [../legal/引用と著作権.md](../legal/引用と著作権.md)

## 要点

- **声の規約と見た目の規約は別。** VOICEVOX はキャラクターとソフトウェアで権利者が異なると明言し、東北ずん子・ずんだもんプロジェクトは「VOICEVOXのクレジットは音源の利用条件」で、イラスト・立ち絵の条件を満たしたことにはならないとしている。 【一次】[S1][S5]
- 立ち絵は**3層**で確認する: キャラクターの権利者の規約（例: zunko.jp のガイドライン）＋立ち絵素材の作者の規約（ファンが描いた二次創作の場合）＋声の規約。 【一次】[S4][S5]／【二次】[S10]
- VOICEVOX の GitHub のリソース（立ち絵画像を含む）は、スクリプト以外「VOICEVOX の開発のための利用のみ許可されます」。エンジンの API は立ち絵画像（portrait）を返すが、そこから取った画像を動画に使ってよいとはどこにも書かれていない。公式Q&Aは、立ち絵は「ボイボ寮から各キャラクターのホームページ」を見るよう案内している。 【一次】[S1][S2][S3]
- 東北ずん子・ずんだもんプロジェクト（ずんだもん、四国めたん等）の公式イラストは、個人のクリエイターなら**非商用は申請なし・無料**。個人の YouTube の広告収入やスーパーチャットは「非商用の範囲」とされ、企業所属の YouTuber・VTuber の配信や、それを編集した動画も無料の範囲。 【一次】[S4]
- 同プロジェクトでも、**スポンサーが付く PR 案件**で立ち絵を使うのは有償の商用ライセンス。目安は国内30万円（税別）、海外を含めると50万円（税別）で、動画10本・合計20分まで。申請と支払いは発注企業が行う。 【一次】[S4][S5]
- 公式イラストは、元のキャラクターが誰かわかる範囲なら**切り抜き、色の変更、フィルタ、吹き出しや図形の重ね、服装の変更**ができる。縦横比の変更は「少しくらいなら」。コピーライト表記（©）は不要。 【一次】[S4][S5]
- 禁止事項には、政治・宗教（応援・批判に加え「情報を提供する目的」も）、他者や特定組織（国家を含む）への非難、キャラクターが残虐な行為をする・される利用、**「嘘やフェイク」**、情報商材、キャラクター素材そのものの販売などがある。 【一次】[S4]
- 他人が描いた二次創作の立ち絵は、その作者の規約も守る。ずんだもん等の動画で多く使われる坂本アヒル氏の立ち絵素材について、二次資料は「公式の規約の範囲なら何に使ってもだいじょうぶ！」という配布ページの文言を引用している。一方、公式Q&Aは、坂本アヒル氏のイラストは個人向けの小口電子データライセンスを使った販売・提供には使えないとしている。 【二次】[S8][S9]／【一次】[S5]
- **生成AI**: 同プロジェクトの公式イラストをもとにした AI 作画は可能。公式イラストを学習した LoRA の配布も可。他人の二次創作イラストを AI に入れることは別の許可が必要。 【一次】[S5][S6]
- YouTube の**有料メンバーシップ特典**（バッジ・カスタム絵文字）にキャラクターを使うには、個人向けの小口電子データライセンスへの登録が必要。動画を販売ページに埋め込むと「広告と同様の扱い」になる。 【一次】[S5]
- ガイドラインは予告なく変わることがあり、ガイドラインに従って作った二次的著作物は、配信や放送への利用を SSS 社に許諾したことになると定めている。 【一次】[S4]
- 2023-03-28 の規約改定で、動画の広告収益化や投げ銭などの「非商用」の範囲なら企業所属のストリーマーも問い合わせなしで無償利用できるようになった（報道による）。2023年10月には公式が、個人・団体への非難や誹謗中傷にキャラクターを使わないよう注意を呼びかけた（報道による）。 【二次】[S8]

### 5. ファンが配布する立ち絵素材（二次創作）

#### 5-1. 公式の考え方

- 他人の二次創作を使うときは、その作者の許可・意向を確認する。 【一次】[S4]
> 「イラストページにあるものは使っても大丈夫ですが、2次創作者のイラスト、ボカロ曲は別です。
> 個別に許可を取る必要があったり、クレジットが必要なものがあったりさまざまなので2次創作に関しては2次創作者の意向を確認しましょう。」[S4]
- 「（ず・ω・きょ）」と書かれた二次創作は「東北ずん子・ずんだもんプロジェクトガイドライン準拠」という意味で、東北企業やクリエイターが自由に使えるものになる、とガイドラインは説明している。 【一次】[S4]
- 小口電子データライセンスに登録しても、第三者が作った素材の条件まで満たすわけではない。公式Q&Aは例として坂本アヒル氏を挙げている。 【一次】[S5]
> 「例えば、坂本アヒル氏のイラストは、小口電子データライセンスを使った販売・提供には利用できません。」[S5]

## このチャンネルでの使い方（提案）

> ※この節は上の事実から導いた提案で、事実ではない。

- **最初に決めるのは、既存キャラクターの見た目を使うか、オリジナルの見た目を作るか。** 既存キャラクターなら、声の規約・キャラクターの規約・立ち絵作者の規約の3つを守り、立ち絵作者のクレジットも必要になることがある。オリジナルの見た目に VOICEVOX の声を当てるなら、見た目の規約は自分たちのものになり、声の規約（クレジット等）だけが残る。ただし声のキャラクターによっては、その声を他のキャラクターの CV として使うことに条件がある（もち子さんの例、[VOICEVOX利用規約.md](VOICEVOX利用規約.md)）。（根拠: [S1][S4][S5][S10]）
- **既存キャラクターを使うなら、規約の一次資料を読めるずんずんPJ系（ずんだもん、四国めたん 等）を優先する。** 公式イラストは個人の動画の広告収益まで無料・申請不要で、加工の範囲も具体的に書かれている。（根拠: [S4][S5][S6]）
- **立ち絵は公式素材か、規約を原文で確認した二次創作素材だけを使い、エンジンの portrait 画像やリポジトリの画像は使わない。** VOICEVOX のリソースは開発目的に限られている。（根拠: [S1][S2][S3]）
- **立ち絵素材を使ったら、作者のクレジットを概要欄に声のクレジットと並べて書く。** ずんずんPJの公式イラストは表記不要だが、二次創作の作者は表記を求める場合がある（浅井麻氏の例）。例:
  ```
  VOICEVOX:ずんだもん
  VOICEVOX:四国めたん
  立ち絵：坂本アヒル 様
  ```
  （根拠: [S4][S10]）
- **企業案件（mod・サーバー・企業のスポンサー）は立ち絵を出さない回にするか、発注企業に有償ライセンスを取ってもらう。** 立ち絵を使う PR 案件は国内30万円（税別）からで、申請は発注企業。案件の表示義務は [../legal/ステルスマーケティング規制.md](../legal/ステルスマーケティング規制.md)。（根拠: [S4][S5]）
- **メンバーシップを始めるときは、キャラクターのバッジ・絵文字を使う前に小口電子データライセンスの条件を確認する。**（根拠: [S5]）
- **台本の注意（見た目の規約からも）:** キャラクターに他のチャンネル・個人・団体を名指しで批判させない。政治・宗教の団体や人物の「情報を提供する」だけでも禁止項目に入る。物理学史を扱う回（例: ガリレオと教会の対立）でずんずんPJ系のキャラクターを使うときは、宗教団体への批評・批判や宗教団体の情報提供に当たらないかを人の関門で確認する。（根拠: [S4][S8]）
- **AIで表情差分やポーズを作るなら、ずんずんPJの公式イラストを元にする。** 坂本アヒル氏など第三者の立ち絵を AI に入れるのは、その作者の許可がない限りしない。（根拠: [S5][S6]）
- **チャンネルのアイコン・バナーに既存キャラクターを使うかは保留にする。** ずんずんPJのガイドラインに直接の記述が見つからず、二次創作の立ち絵には「SNSアイコン等も不可」とする作者もいる。（根拠: [S4][S10]）
- **規約は予告なく変わるので、使っている素材の規約ページの取得日を制作記録に残し、定期的に読み直す。**（根拠: [S4]）
