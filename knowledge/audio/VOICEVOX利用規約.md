# VOICEVOX利用規約

> 対象: VOICEVOX（エディタ・エンジン・コア）の利用規約と、音声ライブラリ（キャラクターの声）ごとの条件。クレジット表記の書式と置き場所、商用・YouTube収益化の可否、禁止事項、クレジット省略ライセンス、規約の所在URL。キャラクターの見た目（立ち絵・イラスト）の規約は別ファイル。
> 使う場面: 声のキャラクターを選ぶとき／台本を書くとき（禁止される内容の確認）／概要欄・動画内のクレジットを作るとき／企業案件を受けるとき／投稿前のチェック。
> 調査日: 2026-11-19 ／ 対象ソフト: VOICEVOX エディタ 0.26.3（公式サイトの表示、2026-11-19 取得）。MCとは無関係。

## 要点

- 規約は**ソフトウェア（VOICEVOX）**と**音声ライブラリ（キャラクターごと）**の二層で、両方を守る必要がある。ソフトの規約自体が「各音声ライブラリの規約に従ってください」と定めている。さらにキャラクターの見た目は別の規約（[キャラクター立ち絵の規約.md](キャラクター立ち絵の規約.md)）。 【一次】[S1][S3]
- VOICEVOX ソフトウェアは商用・非商用を問わず使えるが、「VOICEVOX を利用したことがわかるクレジット表記」が必須。 【一次】[S1]
- クレジットの書式は、各キャラクターについて VOICEVOX が示す「VOICEVOX:キャラクター名」（例「VOICEVOX:ずんだもん」）。一部のキャラクターは CV 名などを含む指定の文字列がある（もち子さん「VOICEVOX:もち子(cv 明日葉よもぎ)」、Voidoll「VOICEVOX:Voidoll(CV:丹下桜)」、ユーレイちゃん「VOICEVOX:ユーレイちゃん(CV:神崎零)」、里石ユカ「VOICEVOX:里石ユカ（つぼみ）」）。 【一次】[S3][S5][S6]
- 動画のクレジットの置き場所は、VOICEVOX 公式Q&Aでは「動画の概要欄や動画内など」。東北ずん子・ずんだもんプロジェクトの音源規約では「ユーザーが気になって見にいった際にはわかる程度のところ」。複数キャラクターを使うときは**キャラクターごとに**記載する。 【一次】[S3][S15][S16]
- 2026-11-19 時点で VOICEVOX 公式サイトに載っているキャラクターは44人。VOICEVOX が示す要約では、37人は「クレジットを記載すれば、商用・非商用で利用可能です」という案内だけ。残り7人（No.7、ユーレイちゃん、青山龍星、もち子さん、後鬼、Voidoll、ぞん子）には、非商用限定・企業の関与時の事前確認・商用時の問い合わせなどの追加条件がある。 【一次】[S2][S4][S5][S6]
- No.7 とユーレイちゃんは「非商用（同人利用や配信による収入はOK）」で、その他の商用利用は権利者への事前確認が必要。YouTube 動画の広告収益がこの「配信による収入」に入るかは、要約からは読み取れない（キャラクター側の規約原文は未読）。 【一次】[S5][S6]
- ずんだもん・四国めたん・九州そら・東北ずん子・東北きりたん・東北イタコ・中国うさぎ・中部つるぎ・あんこもんの9人は同じ「音源利用規約」（zunko.jp）に従う。禁止事項に、政治・宗教、特定の個人・団体（国家を含む）を非難・批判・応援する目的、情報商材、**「意図的に虚偽の情報や誤解を招く内容を作成、共有、または拡散する目的」**などがある。 【一次】[S15]
- 上記9人の音源は、クレジットを付けない商用利用が「１キャラクター毎に４０万円（＋消費税）」の契約で可能。公式Q&Aによればこれは1キャラクターごとの買い切りで、動画ごと・毎年の支払いではない。非商用や社内利用でもクレジットは省略できない。 【一次】[S15][S16]
- 2025-09-06 の公式Q&Aの改訂で、「VOICEVOX:」の部分を含むクレジット省略の有償ライセンスは、**キャラクター権利者が窓口**になると明記された。 【一次】[S3][S13]
- モーフィング（2人の声を混ぜる機能）を使った音声には両方の規約が適用され、**より厳しい方が優先**される。音声の中間表現（AudioQuery）を VOICEVOX 以外の音声合成に使う場合もクレジットが必要。 【一次】[S3]
- プログラムから使う「VOICEVOX ENGINE」は HTTP サーバーで、エンジンの規約はソフトウェア（エディタ）の規約と違い「アプリケーションに組み込んで再配布することができます」とある。エンジンの `/speaker_info` API はキャラクターの規約要約（policy.md。クレジットの文字列を含む）を返す。 【一次】[S5][S6][S8][S9]
- キャラクターのいない「VOICEVOX Nemo」は、クレジット「VOICEVOX Nemo」で商用・非商用可。禁止事項に「機械学習での利用」がある。 【一次】[S5][S14]
- 規約を守れているかの個別質問には、VOICEVOX・東北ずん子プロジェクトとも原則答えない。東北ずん子プロジェクトは個別回答を税込10,000円の有償サービスとしており、「AIから「念のため公式に問い合わせましょう」と言われました。確認してもらえますか？」という質問項目まで公式Q&Aにある。 【一次】[S3][S15][S16]

## 詳細

### 1. 規約の構造（三層）

- VOICEVOX ソフトウェアの規約は、作った音声を使うときは「各音声ライブラリの規約に従ってください」と定める。 【一次】[S1]
- VOICEVOX 公式Q&Aは、キャラクターとソフトウェアで権利者が異なり、キャラクターに関する質問には VOICEVOX は答えられないとしている。 【一次】[S3]
> 「VOICEVOX は、キャラクターとソフトウェアで権利者が異なります。
> キャラクターに関することを VOICEVOX からお答えすることはできません。
> キャラクター権利者様にお問い合わせください。」[S3]
- 東北ずん子・ずんだもんプロジェクトの公式Q&Aは、VOICEVOX のクレジットは音源の利用条件であり、イラスト・立ち絵の利用条件を満たしたことにはならないとしている（見た目の規約は [キャラクター立ち絵の規約.md](キャラクター立ち絵の規約.md)）。 【一次】[S16]
> 「VOICEVOXのクレジットは音源の利用条件です。
> キャラクターのイラスト・立ち絵の利用条件を満たしたことにはなりません。」[S16]
- VOICEVOX はキャラクターを含まない OSS 版と、キャラクター（声と見た目）を含む製品版に分かれている。理由は、キャラクターのライセンスにある「公序良俗に反する利用の禁止」「反社会的勢力の排除」が、オープンソースの定義の「利用する分野に対する差別の禁止」と衝突するため。 【一次】[S10]

### 2. VOICEVOX ソフトウェア利用規約（全文の要旨と原文）

公式サイトの「VOICEVOX ソフトウェア利用規約」は短く、内容は次のとおり。 【一次】[S1]

> - 作成された音声の利用を他者に許諾する際は、当該他者に対し本許諾内容の 2 及び 3 の遵守を義務付けてください
> ## 禁止事項
> - 本ソフトウェアの全てまたは一部を無断で再配布すること
> - 逆コンパイル・リバースエンジニアリング及びこれらの方法を公開すること
> - 製作者または第三者に不利益をもたらす行為
> - 公序良俗に反する行為
> （中略）
> ## その他
> ご利用の際は VOICEVOX を利用したことがわかるクレジット表記が必要です。」[S1]

- 公式サイトのソース（GitHub の voicevox_blog リポジトリ）の履歴では、現在の規約ページのファイルは 2024-12-24 のコミット（サイトの Astro への移行）で作られ、その後変更されていない（2026-11-19 時点）。 【一次】[S13]

### 3. エンジン・コアの規約（プログラムから使う場合）

エディタ（GUI）を使わず、プログラムから音声を作る場合に関わるエンジンとコアの規約。

- VOICEVOX は「エディター」「エンジン」「コア」の3つのモジュールでできていて、エンジンはテキスト音声合成 API を Web サーバーの形で公開する。 【一次】[S10]
- エンジンは Windows/macOS/Linux の実行ファイルのほか Docker イメージでも配布されている（README の例: `docker run --rm -p '127.0.0.1:50021:50021' voicevox/voicevox_engine:cpu-latest`、GPU 版は `nvidia-latest`）。 【一次】[S8]
- 製品版エンジンに付く規約（VOICEVOX エンジン利用規約）は、許諾内容に「アプリケーションに組み込んで再配布することができます」があり、禁止事項から「無断で再配布すること」（ソフトウェア規約の禁止事項の1つ目）が外れている点がソフトウェア規約と違う。クレジット表記が必要な点は同じ。コアライブラリの規約も同じ内容。 【一次】[S1][S6][S7]
> 「1. 商用・非商用問わず利用することができます
> 2. アプリケーションに組み込んで再配布することができます
> 3. 作成された音声を利用する際は、各音声ライブラリの規約に従ってください」[S6]
- エンジンのソースコード（OSS 版）のライセンスは「LGPL v3 と、ソースコードの公開が不要な別ライセンスのデュアルライセンス」。 【一次】[S8]
- エンジンの `/speaker_info?speaker_uuid=...` は、キャラクターの情報として `policy`（policy.md の本文）と `portrait`（立ち絵画像）などを返す。 【一次】[S8][S9]
> 「policy: str = Field(description="policy.md")」[S9]

- **キャラクターの第一候補は、規約の原文を読めて条件が明確なずんずんPJ系（ずんだもん、四国めたん など）にする。** 声は VOICEVOX:（キャラクター名）の形のクレジットで商用・非商用とも使え、禁止事項・クレジットの置き場所・省略ライセンスの金額まで一次資料で確認できる。他のキャラクターを使うなら、使う前にその規約の原文を人が読んで、このファイルに追記する。（根拠: [S5][S15][S16]）
- **No.7・ユーレイちゃん・ぞん子は、収益化するチャンネルでは原文を確認するまで使わない。** 要約が非商用限定、または商用は問い合わせが必要という内容で、YouTube 広告収益の扱いが要約から決まらない。（根拠: [S5]）
- **クレジットは概要欄に必ず入れ、長尺は終了画面付近にも出す。** 書式は policy.md の指定の文字列をそのまま使い、使ったキャラクターごとに1行ずつ並べる。例:
  ```
  VOICEVOX:ずんだもん
  VOICEVOX:四国めたん
  ```
  （根拠: [S3][S5][S15][S16]）
- **クレジットの文字列はエンジンの `/speaker_info` から取った policy を見て決め、動画ごとに、使ったキャラクター・VOICEVOX のバージョン・規約を確認した日を制作記録に残す。** 規約や要約はあとから変わることがある（もち子さんの例）。（根拠: [S5][S9][S11]）
- **台本の事実確認は、規約上の義務でもあると考える。** ずんずんPJ系の音源規約は「意図的に虚偽の情報や誤解を招く内容」を禁じている。minecraft_physics リポジトリの CLAUDE.md の決まり（動画で断言してよいのは【実測】か【一次】だけ）と方向が同じ。（根拠: [S15]）
- **他チャンネルの検証動画を名指しで批判する台本は、キャラクターに言わせない。** ずんずんPJ系の音源規約は「特定の個人、団体（国家を含む）を非難・批判するまたは応援する目的での利用」を禁じている。既存の説を確かめる企画でも、相手を特定して否定する形を避け、現象の検証として語る。（根拠: [S15]）
- **モーフィングは使わない。** 規約が二重にかかり、厳しい方が適用される。（根拠: [S3]）
- **生成した音声を別の AI の学習やボイスチェンジャーの素材にしない。** Nemo は明示的に禁止、もち子さんも禁止と引用されている。（根拠: [S14][S17]）
- **企業案件（mod・サーバー・企業のスポンサー）を受けるときは、声と見た目を分けて確認する。** ずんずんPJ系は声だけなら企業の紹介動画にも使えるが、立ち絵を使う案件は別の有償ライセンスになる（[キャラクター立ち絵の規約.md](キャラクター立ち絵の規約.md)）。案件の表示は [../legal/ステルスマーケティング規制.md](../legal/ステルスマーケティング規制.md)。（根拠: [S16]）
- **プログラムからはエンジン（Docker 版も可）を使う。** エンジンの規約はアプリへの組み込みと再配布を認めているので、制作パイプラインの中で動かす形に合う。ただし作った音声の規約（キャラクター側）は変わらない。（根拠: [S6][S8]）
- AI音声の開示（YouTube の「改変または合成されたコンテンツ」）が必要かは [../youtube/AI生成・改変コンテンツの開示.md](../youtube/AI生成・改変コンテンツの開示.md)、AI音声チャンネルの収益化審査のリスクは [../youtube/量産型・再利用コンテンツのポリシー.md](../youtube/量産型・再利用コンテンツのポリシー.md) と [../channel/AI音声チャンネルの事例とリスク.md](../channel/AI音声チャンネルの事例とリスク.md) で確認する。

## わかっていないこと・要確認

- ずんずんPJ系以外のキャラクター（春日部つむぎ、雨晴はう、波音リツ、VirVox Project の各キャラ、冥鳴ひまり、もち子さん、No.7 ほか）の**規約の原文**。このセッションのネットワークでは各公式サイトに接続できず、VOICEVOX 側の要約と二次資料（note 記事）しか読めていない。使うキャラクターが決まったら原文を読む。
- No.7・ユーレイちゃんの「配信による収入はOK」に、YouTube 動画（ライブ配信でない投稿）の広告収益が含まれるか。
- ぞん子の「商用利用の場合は、個別に問い合わせ」の「商用」に YouTube の広告収益が入るか。
- VirVox Project の3人の「商用利用」の扱い（VOICEVOX の要約と note 記事の要約が食い違う）と、YouTube の広告収益・企業案件で使えるか。
- ずんずんPJ系の音源規約の「嘘やフェイク」の項がいつ追加されたか（ページに日付がない）。
- ショート動画だけで使う場合のクレジットの置き場所についての公式の記述（概要欄でよいか）は見つかっていない。
- VOICEVOX 互換の他のエンジン（COEIROINK、AivisSpeech など）を VOICEVOX エディタから使う場合の規約は調べていない。
- 東北ずん子・ずんだもんプロジェクトの規約の改定履歴（公式の日付つきの記録）。2023-03-28 の改定はイラストの規約として [キャラクター立ち絵の規約.md](キャラクター立ち絵の規約.md) に二次資料で記録した。
