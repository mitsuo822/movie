# コメント欄の運営

> 対象: YouTube のコメント設定とモデレーション、Studio での確認と返信、誤りの指摘を拾う道具（フィルタ・AI検索・要約・API）、視聴者が付ける『メモ』、コメント運営の研究。
> 使う場面: チャンネルの初期設定、公開後のコメント確認と返信、誤りの指摘を訂正につなげるとき。
> 調査日: 2026-11-20 ／ mc_version: 対象外（MCに依存しない）
> 関連: [事実確認と訂正.md](../script/事実確認と訂正.md), [子ども向け設定.md](../youtube/子ども向け設定.md), [API投稿.md](../youtube/API投稿.md), [アナリティクス指標.md](../youtube/アナリティクス指標.md), [推薦の仕組み.md](../youtube/推薦の仕組み.md), [新規チャンネルの立ち上げ.md](新規チャンネルの立ち上げ.md)

## 要点
- コメント機能は動画ごとにオン・一時停止・オフ。オンのときの保留は「なし」「基本」「厳格」「すべて保留」の4段階。【一次】[S1]
- 保留中のコメントは最長60日 Studio に残り、承認しない限り公開されない。【一次】[S1]
- 「基本」「厳格」の判定は AI で、常に正しいとは限らないと YouTube 自身が書いている。【一次】[S1]
- ブロックする単語・リンクのブロック・ユーザーの非表示は、チャンネルのすべての動画に効く（1本だけには適用できない）。【一次】[S1]
- 承認済みユーザーのコメントはフィルタを通らない。自分・モデレーター・承認済みユーザーのリンク付きコメントは保留されない。【一次】[S1]
- 「子ども向け」の動画ではコメントが無効になる。非公開動画ではコメント設定を変えられない（限定公開なら可）。【一次】[S4]
- Studio では質問を含むか・回答ステータスで絞り込め、パソコン版には意味で探す AI 検索（類似・トピック検索は過去90日分）とコメントの要約がある。【一次】[S2]
- モデレーターは標準と管理の2種類。追加しても本人に通知は行かず、モデレーターは Studio に入れない。【一次】[S3]
- Data API の commentThreads.list は1回1ユニットで、searchTerms で語句を含むコメントを取れる。【一次】[S7]
- API で rejected にしたコメントは published に戻せない（setModerationStatus は1回50ユニット）。【一次】[S8]
- 視聴者が補足を付ける『メモ』を書けるのは、取得時点（2026-11-20）でも米国・英語だけ。【一次】[S9][S10]
- 研究（arXiv の要旨のみ読んだ）では、YouTube のクリエイターのハートでコメントが目立ち、好意的な反応が増えた（2024-04）。作り手19人への聞き取りでは、単語フィルタを書くことも整理・見直すことも難しいと答えた（2022-02）。【二次】[S12][S11]

## 詳細

### 1. 動画ごとのコメント設定と保留の段階
- 動画ごとにコメント機能をオン・一時停止・オフから選び、オンのときは保留の段階を次の4つから選ぶ。【一次】[S1]

| 段階 | YouTube の説明 | 確度 | 出典 |
|---|---|---|---|
| なし | コメントを保留しない | 【一次】 | [S1] |
| 基本 | 不適切な可能性があるコメントを保留する | 【一次】 | [S1] |
| 厳格 | 不適切な可能性がある多様なコメントを保留する（基本より保留が増える） | 【一次】 | [S1] |
| すべて保留 | すべてのコメントを保留する | 【一次】 | [S1] |

- 「基本」で保留されるものの例として、YouTube はスパム・個人的な宣伝・意味不明の発言・不適切な可能性のあるコメントを挙げている。【一次】[S1]
- 判定は AI によるもので、誤りがありうると明記されている。精度と数は今後変わりうるともしている。【一次】[S1]
  > 「これらの設定では AI を使用して保留の必要があるコメントを検出するため、常に正しいとは限りません。」[S1]
- 保留中のコメントは最長60日間 Studio に残り、承認しない限り公開されない。【一次】[S1]
- コメントできる人を「チャンネル登録者とメンバー」に限り、必要な登録期間を「登録期間の指定なし」「1 時間」「1 日」「1 週間」から選べる。この限定はチャンネル単位ではできず、動画ごと（一括編集を含む）に設定する。【一次】[S1]
- 一時停止は、既存のコメントを残したまま新しいコメントだけを止める。YouTube は、コメントが急に増えたときに確認の時間をとる使い方を例に挙げている。【一次】[S1]
- オフにすると既存のコメントも見えなくなり、オンに戻すと再び表示される。【一次】[S1]

### 2. デフォルト設定・設定を変えられない場合・並び順
- デフォルトのコメント設定は新しい動画と投稿にだけ効き、既存の動画は変わらない。【一次】[S4][S1]
- 個々の動画の設定は Studio の [コンテンツ] → 動画 → [さらに表示] → [コメントと評価] で変え、一括編集で複数の動画をまとめて変えられる。【一次】[S4]
- 次の場合はコメント設定を変えられない: 視聴者を「子ども向け」に設定している（コメントは無効になる）、動画が非公開（限定公開なら設定できる）、管理対象のアカウントで使っている。【一次】[S4]
- 視聴ページでのコメントの並び順は、動画ごとに [人気順] か [新しい順] を選べる。【一次】[S4]
- Studio のコメント一覧は、既定で [関連性の高い順] に並び、よく使うフィルタを既定として保存できる。【一次】[S4]

### 3. チャンネル全体の設定（ブロックする単語・リンク・ユーザー）
- Studio の設定の [コミュニティの管理] → [コンテンツ管理] で、新しい動画と投稿へのコメント、チャット、コミュニティの投稿、ブロックする単語、リンクテキストの扱いをまとめて設定する。ブロックする単語はコメント・チャット・コミュニティの投稿に効き、カンマ区切りで入力する。【一次】[S5]
- ブロックする単語を含むコメントや、それにほぼ一致するコメントは最大60日間保留され、[コメント] ページの [保留中] タブで確認・承認できる。【一次】[S1]
- ブロックする単語は、動画やライブ配信のクリップを作るときにも使えなくなる。【一次】[S1]
- リンクテキストをオンにすると、ハッシュタグや URL を含むコメントが保留される。【一次】[S5][S1]
- ただし、自分・モデレーター・承認済みユーザーのリンク付きコメントは保留されない。【一次】[S1]
  > 「リンクを含むコメントがご自身、コメント モデレーター、承認されたユーザーによって投稿されたものである場合、ブロックされることはありません。」[S1]
- 承認済みユーザーのコメントはフィルタを通らず自動で公開される。【一次】[S1]
- 非表示にしたユーザーのコメントは、すべての動画で表示されず、Studio でも見られない。非表示のユーザーはクリップも作れない。【一次】[S1]
- これらは1本の動画だけには適用できない。【一次】[S1]
  > 「ユーザーの非表示、単語のブロック、リンクのブロックは、自動的にすべての動画とチャンネル ホームページに適用されます。」[S1]
- 設定の変更は今後のコメントに効く。既存のコメントが変わるのは、コメント機能をオフにしたときと、ユーザーを非表示にしたときだけ。【一次】[S1]

### 4. Studio での確認・返信・ハート・固定
- コメントは Studio の左メニュー [コミュニティ] で確認する。タブは [公開済み] と [保留中] で、保留中には自分の設定で保留されたものと、YouTube がスパムの可能性で自動的に保留したものが入る。【一次】[S2]
- 保留中のコメントには、承認・削除・報告・ユーザーを非表示、の操作ができる。公開済みのコメントからは「常に承認する」を選び、そのユーザーの今後のコメントをすべて自動で承認・公開するようにもできる。【一次】[S3]
- スパムとして報告したコメントは、チャンネルで永久に非表示になる。【一次】[S3]
- 公開済みのコメントには、返信・ハート（複数に一度に付けられる）・高評価・低評価・固定ができる。固定は、個々の動画のコメントを見ているときだけ出る。【一次】[S2]
- Studio では投稿者の名前の横に、上位のコメント投稿者・チャンネルメンバー・登録を公開している人などのバッジが出る。【一次】[S2]

### 5. 誤りの指摘を探す道具（フィルタ・AI検索・要約）
- フィルタバーで、キーワード・質問が含まれるか・回答ステータス・コンテンツの種類（動画、ショート動画、自分の投稿など）で絞り込める。【一次】[S2]
- パソコン版 Studio には、キーワードの一致だけでなく意味で探す AI の検索がある。最大100文字のクエリで探す、おすすめのトピックを使う、あるコメントに似たコメントを探す、の3通り。【一次】[S2]
- キーワードの一致はすべてのコメントから探すが、類似・トピック別の検索は過去90日分が対象で、特定のユーザーのコメントは探せない。【一次】[S2]
  > 「注: この検索ツールは、すべてのコメントから一致するキーワードを検索し、過去 90 日間の類似のコメントやトピック別のコメントを検索します。」[S2]
- 動画ごとに、AI によるコメントの要約（[要約を取得]）を出せる。コメントが少ないとこの選択肢が出ないことがある。【一次】[S2]

### 6. 返信文の候補（AI）
- Studio と YouTube アプリ・Studio アプリには返信文の候補が出る。もとは、クリエイターがよく使う返信文に基づく。【一次】[S6]
- 一部は「アップグレード」版で、自分が最近チャンネルに書いたコメントをもとに、AI が自分の口調に合わせて提案する。使うかどうかは任意で、編集してから送れる。【一次】[S6]
  > 「アップグレードされたコメント返信文候補は自動的な提案であるため、常に適切であるとは限りません。」[S6]

### 7. モデレーター
- YouTube チャンネルを持っている人なら誰でもモデレーターにできる。【一次】[S3]
- 追加は Studio の [設定] → [コミュニティ] の [標準モデレーター] 欄に相手のチャンネル URL を入れる方法と、アプリで相手のコメントの [モデレーターとして追加] から [管理モデレーター] か [標準モデレーター] を選ぶ方法がある。【一次】[S3]
- 管理モデレーターは標準モデレーターより多くの操作ができ、どちらもコメントを保留にできる。モデレーターは Studio には入れない。【一次】[S3]
- 追加しても本人に通知は行かないので、自分で伝える必要がある。【一次】[S3]

投稿の API 全般は [API投稿.md](../youtube/API投稿.md) を参照。ここではコメントに関するものだけを書く。

| メソッド | 要点 | 確度 | 出典 |
|---|---|---|---|
| commentThreads.list | 1回1ユニット。videoId（動画）・allThreadsRelatedToChannelId（チャンネル）・id のどれか1つで絞る | 【一次】 | [S7] |
| 〃 主なパラメータ | maxResults は1〜100（既定20）。order は time（既定）か relevance。searchTerms は指定した語句を含むコメントだけを返す。textFormat は html（既定）か plainText | 【一次】 | [S7] |
| 〃 moderationStatus | heldForReview（レビュー待ち）・likelySpam（スパムの可能性が高い）・published（既定）。権限のあるリクエストのみ | 【一次】 | [S7] |
| 〃 エラー | コメントが無効な動画では 403 commentsDisabled | 【一次】 | [S7] |
| comments.setModerationStatus | 1回50ユニット。youtube.force-ssl のスコープが必要。ID は最大50個 | 【一次】 | [S8] |
| 〃 moderationStatus | heldForReview・published・rejected | 【一次】 | [S8] |
| 〃 banAuthor | true でその作成者の今後のコメントも自動で不承認。rejected のときだけ有効 | 【一次】 | [S8] |

- rejected にすると、そのコメントへの返信もすべて非表示になり、published には戻せない。【一次】[S8]
> 「不承認のコメントのモデレーション ステータスを published に変更することはできません。」[S8]
> 「この操作を行うと、不承認のコメントへの返信もすべて非表示になります。」[S8]

### 9. 視聴者が付ける『メモ』（YouTube の補足機能）
- YouTube は 2024-06-17 に、視聴者が動画に補足のメモを付ける機能の試験を始めると発表した。最初はモバイル・米国・英語だけ。【一次】[S10]
- メモは幅広く役に立つと評価されたときに公開される。2024-06-17 の発表では、評価の集約に bridging-based algorithm（過去に評価が分かれていた人の多くが同じメモを役に立つと評価すると、そのメモが表示されやすくなる方式）を使うとした。【一次】[S10]
- 同じ発表では、最初の試験では第三者の評価担当者（YouTube の検索結果やおすすめにフィードバックをしている人たち）が評価し、試験が進めば投稿者自身にも評価してもらう予定とした。取得時点（2026-11-20）のヘルプは、メモは「他の評価担当者によって審査と評価が行われます」と書いている。【一次】[S10][S9]
  > 「（訳）メモは幅広く役に立つと判断された場合に、動画の下に公開される」 原文: 「Notes will appear publicly under a video if they’re found to be broadly helpful.」[S10]
- 取得時点（2026-11-20）のヘルプでも、メモを書けるのは米国・英語だけ。【一次】[S9]
  > 「注釈の作成機能は、米国内で英語でのみご利用いただけます。」[S9]
- メモを書くには、作成から6か月以上たったチャンネルで、過去12か月に違反警告がなく、管理対象アカウントやブランドアカウントでないことなどが条件。【一次】[S9]
- メモにはタイムスタンプと出典リンクを付けられ、匿名で公開される。書き方のヒントとして600文字以下で入力するよう求めている。【一次】[S9]
- 未成年者が登場する可能性のある動画・子ども向け・非公開の動画には付けられない。【一次】[S9]
- メモを書けない人でも、モバイルとパソコンでメモを見ることはある。【一次】[S9]

### 10. コメント運営に関する研究
いずれも arXiv に投稿された論文で、読んだのは要旨だけ。著者の所属は読んだページでは確認していないが、プラットフォーム（YouTube）の技術者による論文とは確認できないため【二次】として扱う。

| 研究 | 条件 | 結果 | 確度 | 出典 |

| Choi ほか『Creator Hearts』（2024-04） | YouTube のハートの効果を定量化 | ハートでコメントが目立ち、好意的な反応が増えた。公開直後のハート付きコメントは、視聴者がコメントする動機になりうる | 【二次】 | [S12] |
| Shim・Jhaver『The Pin of Shame』（2025-05、v2 2026-06） | 否定的なコメントを固定したことのある作り手20人への聞き取り | 罰・教育・印象管理に使われるが、公開でさらすことには危険もある | 【二次】 | [S13] |
| Shim・Jhaver『Reply, Delete, or Ignore?』（2026-08） | 作り手584人への質問紙調査（憎悪コメントへの対応） | 安全には削除が最も有益と見られた。返信はアルゴリズム上の利益が最大と見られたが、その見込みは各方法を採る意向を有意に予測しなかった（安全と印象管理の見込みは予測した） | 【二次】 | [S14] |

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。

- **コメントはオン、保留は基本から始め、保留中タブを週1回見る。** 保留は最長60日で AI の判定は誤りうる。（根拠: [S1]）
- **子ども向けには設定しない。** 誤りの指摘の受け口がなくなる（判断は [子ども向け設定.md](../youtube/子ども向け設定.md)）。（根拠: [S4]）
- **リンクテキストはオンにし、出典リンクは自分の固定コメントで出す。** 自分のリンクは保留されない。（根拠: [S5][S1]）
- **ブロックする単語は少なく始め、追加の理由を記録する。** 全動画に効くので一般語を入れると無関係なコメントまで保留される。（根拠: [S1][S11][S15]）
- **誤りの指摘を拾う手順（公開後）:**
  1. Studio の [コミュニティ] で、質問を含むコメントと未返信のコメントに絞る。（根拠: [S2]）
  2. パソコン版の AI 検索で `計測値の誤りの指摘`、`バージョンの違い` のようなトピックを探す。類似・トピック検索は過去90日分なので、公開から90日以内に行う。（根拠: [S2]）
  3. 必要なら commentThreads.list に searchTerms（`間違`、`違う`、`実際は` など）を付けて取り出し、一覧にする。（根拠: [S7]）
  4. 確認した誤りは訂正し（[事実確認と訂正.md](../script/事実確認と訂正.md)）、指摘に返信とハートを付け、訂正を固定コメントにする。物理の知見は `minecraft_physics/knowledge/` に戻す。（根拠: [S2][S12]）
- **API で自動的に rejected にしない。** 取り消せないので、自動化は heldForReview に回すまでにし、人が決める。（根拠: [S8]）
- **ハートは公開直後から付ける。** 効果は自分たちのアナリティクスで確かめる（[アナリティクス指標.md](../youtube/アナリティクス指標.md)）。（根拠: [S12]）
- **AI の返信候補は直してから送る。不適切なコメントを固定してさらさない。**（根拠: [S6][S13]）
- **荒れたら一時停止を使う。『メモ』は当てにせず、指摘はコメント欄で受ける。**（根拠: [S1][S9]）

## わかっていないこと・要確認
- 新しいチャンネルの保留の初期値（ヘルプに記載を見つけられなかった）。Studio で実際の値を確認する。
- メニュー名がページごとに違う（[S3] は [設定] → [コミュニティ]、[S5] は [コミュニティの管理] → [コンテンツ管理]、2022年の [S15] は自動フィルタ）。実際の画面で確かめる。
- 旧モデレーターのヘルプ（answer/7023301）は取得時（2026-11-20）に [S1] へ転送された。標準と管理のモデレーターの権限の違いの一覧は、読んだページになかった。
- ブロックする単語の上限数と、「ほぼ一致」の判定（表記ゆれ・ひらがなとカタカナ）の仕組み。
- コメントや返信が推薦に影響するか（[S14] は作り手の見込みだけ）。推薦は [推薦の仕組み.md](../youtube/推薦の仕組み.md)。
- YouTube がセンシティブ判定をコメントなども含めて行うという説は、個人の note の推測（「などから総合的に判断している可能性が高いです。」）でしか見ておらず、公式の資料は見つけていない。【未確認】[S16]
- 『メモ』が日本語の動画に表示されるか、日本で書けるようになる時期。
- AI 検索とコメントの要約が日本語のコメントで使えるか（アップグレード版の返信候補は、YouTube コメントがサポートする全言語で使えるとヘルプにある [S6]）。
- Creator Hearts の対象期間・動画数・因果の推定方法（要旨からはわからない）。
