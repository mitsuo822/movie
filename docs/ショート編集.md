# ショート編集（ドパガキ編集）の仕様

状態: 叩き台（2026-11-18）。M4 で Remotion のテンプレートにする。
ねらい: 長尺の一番の見せ場を、**刺激の密度を最大にして**30〜60秒に詰める。最後まで見させて、繰り返し再生させ、長尺へ誘導する。

## 1. 構成

| 時間 | 中身 |
|---|---|
| 0.0〜1.0秒 | **結果の衝撃的な一瞬**、または問いを大きな文字で。説明やあいさつは入れない |
| 1〜45秒 | 3〜5拍。1拍ごとに「驚き → 理由を一言 → 次の驚き」 |
| 最後の数秒 | オチ。冒頭の場面につながる終わり方にして、ループ再生させる |

## 2. 演出の部品（テンプレートで自動的に付ける）

| 部品 | 規則（初期値。数字を見ながら調整して `knowledge/editing/` に記録する） |
|---|---|
| カット | 0.5〜1.5秒ごと。同じ画が2秒以上続かない |
| ズーム | カットの頭で軽く寄る（パンチイン）。強調語のたびに瞬間的に寄る |
| 字幕 | 全部の台詞に付ける。画面中央付近に大きく。強調語は色と大きさを変え、跳ねるように出す |
| 効果音 | カットのたび、強調語のたび。種類を決めた効果音の一式から選ぶ |
| 速度 | 見せ場の直前でスロー → 本番で通常速度、のように速度を変える |
| 数字 | 大きく数字が増えていく演出（例: 0 → 32 m/s²） |
| 語りの速さ | 長尺より速くする。読み上げの速さを上げ、言葉の間を詰める |
| BGM | テンポの速い曲。台詞の間は音量を下げる |

## 3. 自動化の流れ

1. 長尺の台帳で `highlight` の点数が高い区間を選ぶ。
2. LLMがショート用の台本を書き直す（長尺の台詞の要約ではなく、短く強い言い回しに）。数字は `facts` から取る。
3. 映像は9:16で撮った素材を優先する。
4. テンプレートで上の部品を自動的に付けて書き出す。
5. 検査（長尺と同じ検査に加え、尺が60秒以下か、最初の1秒に動きがあるか）。

## 4. やりすぎを避ける

- 情報が正しいことは崩さない。強調しても、数字や結論は長尺と同じにする。
- 点滅の激しい演出は控えめにする（光過敏への配慮）。
