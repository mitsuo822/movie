# YouTube運用の決まりと制約

状態: 叩き台（2026-11-18）。下の内容は記憶にもとづく【未確認】が多い。**公開を始める前に、それぞれ原文で確認して【一次】に直す。**

| 項目 | 内容 | 確度 | 運用への影響 |
|---|---|---|---|
| 量産型コンテンツ | YouTubeパートナープログラムは2025年7月に、従来の「繰り返しの多いコンテンツ」を「Inauthentic content（量産型・反復的なコンテンツ）」として明確化した | 【未確認】 | 無人で量産しない。毎回の実験・結果が違い、人の判断（3つの関門）が入っていることを保つ |
| APIでのアップロード | 2020年7月28日以降に作られ、監査を受けていないAPIプロジェクトからアップロードした動画は、非公開に固定される | 【未確認】 | 当面は非公開でアップロード → 人が公開する。必要になれば監査を申請する |
| 改変・合成コンテンツの開示 | 本物と誤解されうる写実的な合成コンテンツには開示が必要 | 【未確認】 | ゲーム画面とAIナレーションは対象外の可能性が高いが、原文で確認する |
| Minecraftの利用 | Mojangの利用ガイドラインで、ゲーム映像を使った動画の収益化は認められている。公式と誤解される名称・ロゴの使い方は不可 | 【未確認】 | チャンネル名やサムネイルにロゴを使わない。「非公式」の表記を検討 |
| VOICEVOX | キャラクターごとに利用規約があり、「VOICEVOX:キャラクター名」のクレジット表記が必要 | 【未確認】 | 説明欄に自動でクレジットを入れる。使う声ごとに規約を確認する |
| mod | modごとにライセンスと、動画での利用条件が違う | 【未確認】 | `mods.yaml` にライセンスを書き、説明欄に使ったmodを記載する |
| BGM・効果音 | 素材ごとに利用条件が違う | — | 素材の一覧と利用条件を `knowledge/tools/` に記録する |
